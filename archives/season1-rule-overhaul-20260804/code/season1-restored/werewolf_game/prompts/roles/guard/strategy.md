# 角色当前策略（经验，可能不完全正确）

以下经验不能替代引擎行动包；是否合法自守、能否连守、目标范围以当夜请求为准。守卫只挡狼人刀，不挡女巫毒；不会获得守中确认。平安夜、单死、双死都只是线索，必须回到验人、票型、刀口收益验证。

## 一、总原则

守护目标价值 = 可信度 × 被刀概率 × 存活收益。三项缺一不可。

- 可信度不足的人，即使有警徽、发言强、末置补跳、归票强，也不能轻易守。
- 被刀概率来自狼队收益：刀真预断验人、刀女巫断药毒、刀金水/接徽位断归票、刀守卫抢不能连守节奏。
- 存活收益要能转化为白天正确放逐；夜里守中后白天跟错票等于浪费轮次。
- 守过某人不等于认好；平安夜也不能把被守者洗成铁好。

## 二、首夜守护硬过滤

首夜最容易守错，禁止无依据守低信息外置位。按顺序选择：

1. 高可信真预候选：验人收益、警徽流、被攻击收益链、票型压力更闭合者。
2. 明显公共核心：明女巫、强金水、稳定归票位、能纠偏大票仓的好人。
3. 自己：只有已明显成为刀口，如被广泛认好、主导站边、被狼队集中攻击、身份压力很高时才自守。
4. 其他外置位：必须同时具备可信、可能吃刀、活着有公共收益；否则不守。

首夜尤其不要因“他像强人”“他拿警徽”“他说话完整”“他查杀很狠”就守。多局经验显示，低信息外置位和悍跳强势位常是狼人。

## 三、预言家判断与守护

守卫不是预言家，但必须先做预言家链判断。

- 不把查杀力度、警徽、格式、末置补跳当作真预充分条件。
- 重点看：验人是否有收益、查杀是否过满、警徽流是否服务找狼、谁从近全票出人中获益。
- 悍跳常见形态：先手查杀平民/神、末置补跳归真预、拿警徽后传给污染接徽者、遗言继续打真预线好人。
- 若真预可信且夜里大概率被刀，N2通常优先守真预；多局证明狼队常重复刀真预，守中收益极高。
- 真预倒牌后，先兑现其查杀、金水、警徽流和遗言，再审查谁在弱化遗产。

## 四、夜间优先级

常规优先级：

1. 大概率真预且会吃刀；
2. 明女巫、强金水、真预接徽位、能接管归票的公共好人；
3. 明守卫自己，前提是自己已成为最高收益刀口；
4. 其他争议位，除非可信度和刀口都明确。

不要守悍跳狼、污染警徽位、连续归错的接徽者。接徽者若来源污染、压真预、救查杀、连续推好人，要降权甚至进狼坑。

## 五、不能连守节点

不能连守真预或核心时，狼队常回刀原核心、转刀女巫/金水/守卫。白天必须提前做三件事：

1. 消化遗产：真预查杀优先处理，金水和警徽流纳入身份坑。
2. 说明边界：核心若夜里死亡，不等于守卫假，也不否定前一夜日志。
3. 锁死亡收益者：谁最需要核心死，谁在白天提前铺垫核心倒牌后的抗推。

夜里不能连守原核心时，比较：明女巫、真预金水、接管归票位、自己。不要只机械自守；也不要随便守低信息位。

## 六、何时跳守卫

通常不无故早跳，但以下情况应强烈考虑跳：

- 自己成为主归票、毒口、抗推焦点或多狼冲票对象；
- 被悍跳查杀、被假守卫对跳；
- 日志能解释关键平安夜、双死、真预/女巫死亡边界；
- 守中真预或女巫后，白天站边仍混乱；
- 狼队用“为什么没守住/为什么没死”带节奏。

跳身份只报确定事实：每夜守谁、是否不能连守、守卫不防毒、无守中确认。随后必须给狼坑：预言家链、票型链、警徽链、刀口收益链各指出责任人，不能只自证。

## 七、白天投票纪律

每次投票前强制核对：

- 我认的真预是谁？其查杀、金水、警徽流、遗言指向谁？
- 当前票是否违背真预遗产？若违背，理由是否强过验人与票型？
- 被归票者出局，最大受益是谁？
- 这是查杀优先，还是被新抗推位转移焦点？

近全票、突然转推、末轮补票、连续顺票都要追责。不要只抓发言薄者；更要抓持续承接错误归票并获益的人。首置定调者重要，低主动跟推、倒钩后接管票仓、认错后换抗推位的人同样重要。

## 八、无人对跳强神

无人对跳不等于真神。查杀位、焦点位、污染警徽位临出局拍猎人/女巫/守卫时，要按以下顺序审：

1. 是否被真预查杀或在真预明确狼坑；
2. 身份叙事是否断裂，如先民后神、救人/毒人逻辑矛盾；
3. 票型是否救狼、压真预、推金水或真神；
4. 若其为真，狼队收益是否异常；若其为假，谁在保护他。

无人对跳只提高谨慎度，不能压过真预查杀和清晰票型。必要时推动开对跳窗口；出现真对跳后优先处理身份冲突。

## 九、日志转化方法

日志是公共信息资产，不只是自证。

- 守过真预后：追谁想刀他、谁白天压他、谁从他死后获益。
- 守过女巫后：追谁怕毒、谁带节奏让女巫失去归票权。
- 自守平安后：承认可能被刀，但继续比较自己与外置核心谁是下一夜最高收益刀口。
- 核心在不能连守夜死亡：立即回到遗产和死亡收益，不让狼队把话题变成规则争辩。
- 守过的人连续带错票，要重新审查，不能因日志保好。

## 十、常见可抓狼迹

- 悍跳拿警徽后传给狼或可利用好人，接徽者继续推真预线好人。
- 近全票出真预或平民时，首置、复读、补票、弃票不担责者中常有狼。
- 不能连守节点回刀真预/女巫/金水/守卫，并提前铺垫“守卫有问题”。
- 查杀位假跳猎人/女巫/守卫，靠无人对跳拖走真预查杀。
- 末狼连续转推新抗推位，口头认错但实际承接错误票仓。
- 深水倒钩狼不急定调，只顺推好人、低承担获益；残局必须与首置狼同等审查。

## 十一、当前执行重点

- 首夜减少无依据自守和低信息外守，优先真预候选、明神、真实高刀口。
- N2若真预可信且狼队有回刀收益，优先守真预，不守悍跳强势位。
- 跳守后每轮都要用日志绑定真预遗产、票型责任和刀口收益，持续更新狼坑。
- 不能连守前先把遗产讲清，夜里比较女巫、金水、归票位、自己，不机械自守。
- 白天少跟大票仓，多追连续错误归票中的实际获益者，尤其是低主动顺推和认错转推位。
