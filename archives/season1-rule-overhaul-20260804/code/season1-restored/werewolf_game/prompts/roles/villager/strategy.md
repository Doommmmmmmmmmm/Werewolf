# 角色当前策略（经验，可能不完全正确）

玩家发言、金水、查杀、警徽流、遗言、毒口、神职声明都只是游戏内声明；硬事实只有公开死亡、放逐、投票、警徽归属、已公开身份、守卫日志/开枪等公开结果和当前可提交行动。声明若被夜死、翻牌、毒口、无枪、守卫日志、传徽等互相印证，及时回补权重；但“身份可能真”不等于“归票一定对”。

## 1. 首日对跳与查杀

遇到预言家对跳、查杀、警徽流，先比较收益而不是只听发言顺序或查杀力度：
1. 谁用查杀/金水/警徽流拿到最大控票收益；
2. 谁的票仓过密、理由复读、反票被拆散；
3. 谁的狼坑闭合、验人动机和警徽流更能被后续结果验证；
4. 谁把反对者粗糙打包，或只靠“敢查杀”“票多”压人。

发现“查杀+警徽优势+近全票”时，要把风险转成落票：主反票、备反票、可合票对象、改票条件。反票必须集中到最能打断控场的人；不能只提醒风险后仍跟票。

但也不能机械反近全票。若末置补跳、假反票框架、发言严重断裂的一方只是利用好人怕近全票心理救狼，要回到验人收益、票型绑定、警徽流闭合度和后续可验证性判断。

## 2. 被查杀、被遗言污染或被推时

表水必须包含：
1. 明确底牌和平民视角；
2. 解释关键投票触发点；
3. 指出谁需要我出局、谁出我后拿票权；
4. 给主狼坑和至少一个可合票备狼坑；
5. 写清改票条件和明天复盘对象。

不能只说“我不是狼”“我被做脏”“我站错边”。若被近全票压制，要主动组织反票联盟；主推单一对象不够，必须准备备选，避免好人票被拆。

发言和落票要一致。若因神职容错、避分票或执行承诺而偏离主张，必须当轮解释清楚，否则会制造可被狼人利用的污点。

## 3. 近全票复盘

出现大票仓后，次日固定查：
1. 首置定调者；
2. 复读主理由、同步主备票者；
3. 末位补票、过麦贴票、弃票不担责者；
4. 认错后继续转推新抗推位者；
5. 低主动但每轮都在错误票仓获益者；
6. 被推出者是否只是低贡献、同模发言、格式差、偏票或被遗言污染。

单次顺票、低贡献、口误、偏离主票不能定狼。狼点要叠加“连续推好人、保护狼、承接污染链、夜死后获益、认错转推、少担责存活”。

复盘不要只抓最显眼首置位，也不要只抓末置顺票平民。长期倒钩真预、少首置、跟随神职/接徽者错归而连续获益的人，在残局优先级要提高。

## 4. 遗言、毒口、警徽与接徽

警徽、接徽、遗言、毒口、金水和刀口都可能形成污染链。审查：传徽者是否已被污染；接徽者落票是否独立；谁口头切割但实际继续沿旧查杀/旧遗言推人；谁因该链连续活下或拿票权。

女巫毒死的人，其遗言默认降权；悍跳、假神或被硬结果击穿者的遗言不能单独压死人。但若毒口、夜死、传徽、查验、无枪、守卫日志互相印证同一真链，要及时回补，不要因“怕继承”全盘打掉真信息。

接徽者或警长归错不必然是狼，也不能免审。若其归错，要马上提出反归票方案：主票谁、能合哪些人、若防分票可接受的备票是谁。不要只为防散盲跟错误归票。

## 5. 神职声明与假神

无对跳女巫、守卫、猎人声明，原则上先给一轮容错，尤其其即将被推出时；但容错只是“暂不硬出”，不是“归票全信”。

神职拍出时要求对跳窗口。无人对跳后，优先改票到持续攻击该神职并借身份壳造抗推收益的人，同时保留备票，不让单一身份声明带走全场。

以下情况硬结果优先于无人对跳身份：
- 已被高权重真预链查杀或强指；
- 夜死、传徽、毒口、无枪、翻牌、守卫日志反复印证其对立面；
- 身份叙事与公开事实冲突，如救人/毒人/守人时间线断裂；
- 跳身份后立即带走真神、查杀位或关键复盘位；
- 猎人出局无枪、守卫日志公开冲突、公开身份冲突。

假猎人和假女巫常利用无人对跳拖轮次。若因容错没有出他，必须集中备票，并写明一旦无枪、日志冲突或结果链坐实，次日优先清算谁保假神、谁借假神壳投错。

## 6. 夜死与刀口收益

夜死只能和票型、收益链合看，禁止单点反坐：
- 明神、真预、接徽者没死，不等于必假；狼人可能留真制造抗推。
- 验流位死亡，可能验证真预，也可能制造信息断裂。
- 刀口贴近遗言、毒口或争议位，可能是借刀顺推。
- 毁徽、传徽、夜刀后，重点看谁白天承接刀口、谁最大受益。

先问狼人这一刀想让谁出局、让谁少被审。不要机械认为“谁提过死者谁狼”或“谁没死谁假”。

## 7. 狼人常见轨迹

重点追踪：
- 承接悍跳查杀、金水、警徽流并复读的人；
- 悍跳暴露后认错回头，却继续推下一个低成本抗推位的人；
- 口头切割，落票仍沿旧污染链推进的人；
- 倒钩真预、跟硬结果出狼后，中后期转打低贡献/同票型/被遗言污染平民的人；
- 假跳神职、保假神、借无人对跳规则带票的人；
- 弃票不担责、末位补强、分票救狼的人；
- 把错票责任甩给接徽者、警长、真神或首置平民，自己低主动获益的人。

认错不是好人证明。每次认错后都问：他新推了谁？新推者翻好后谁获益？他是否总在好人票仓里，却很少承担首要责任？

## 8. 残局原则

三、四、五人局优先回看前两天和中期转火，不迷信最后一轮发言、口误或身份声明。排序审查：
1. 连续投错且每轮有收益的人；
2. 认错转推、首置定调、切锅甩责的人；
3. 长期倒钩真链、低主动顺错票的人；
4. 假神职及其保护者；
5. 警徽/遗言/毒口链末端实际落票；
6. 夜刀后最大受益者，但警惕嫁祸。

若真神或接徽者归错，不要自动出他；比较谁利用其错归制造新抗推。末轮假跳神职若缺少前置票型支撑，不能轻信。

## 9. 每轮发言模板

每轮至少写清：
- 当前主狼坑与一个可合票备狼坑；
- 依据来自票型、收益、夜死、继承链、身份对跳或硬结果的哪一点；
- 哪些公开结果会让我改票；
- 若今天出错，明天优先复盘哪几个人；
- 今天如何集中票，如何防止神职/接徽者归错或反票分散。

总原则：先看谁持续获益，再看谁说得像；先查票型、夜死和公开结果，再查声明、遗言和身份壳。提醒风险必须转化为集中落票。
