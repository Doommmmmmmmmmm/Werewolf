# 角色当前策略（经验，可能不完全正确）

以下策略只基于近10局复盘，优先保留可执行、可验证的规则。实际对局仍以公开规则、行动包和场上信息为准。

## 总体原则

- 每夜先算屠边：剩余神、民、明身份、可抗推位、可刀位。接近屠民或屠神时，走最短胜利路线，不为做身份多拖轮次。
- 狼队每天必须产出并确认：主刀/备刀、次日主推/备推、谁冲、谁钩、谁机动、硬信息出现后的撤退口径。行动结束前核验实际刀口，禁止漏刀。
- 四狼不能绑定同一叙事。首日最多两狼明确冲，一狼轻站留疑问，一狼倒钩或机动；警徽票和放逐票都要控制暴露度。
- 发言、投票、改票必须一致。若临时改票，次日第一时间解释原判断、改票原因、硬信息变化和后续验证方式。

## 夜间刀法

- 刀前判断三件事：是否推进屠边；是否可能被守/救；死亡后是否会唯一指向某名狼收益。
- 真预、女巫、守卫、强带队位优先处理，但不能机械连刀。高价值目标第一次被守/救后，默认换刀；只有确认不能连守窗口或刀中即胜时才回刀。
- 利用守卫不能连守是核心胜点：若真预、女巫、守卫、接徽金水上一夜被守，下一夜可评估回刀；但撞守当天要预判好人会因此坐实哪些神职链。
- 明猎通常不夜刀、不白天硬推。除非刀后直接胜利或必须赌枪，否则优先走屠民或刀其他神职，避免猎人开枪带狼。
- 终局夜刀优先留下互疑、票型有污点、低贡献、无硬身份的人。避免刀出“唯一收益者就是我”的局面。

## 悍跳与首日设计

- 首夜外置刀加悍跳预言家可用，但悍跳必须完整：验人、理由、警徽流、狼坑、归票、遗言、队友撤退口径。
- 查杀目标优先选平民倾向、难拍身份、发言可攻击、无人强保者。避免查杀女巫、守卫、猎人倾向、真预强势位、已被多人保护或容易自证者。
- 警徽流不能显得控票收益过满：不要把金水、警徽、连续警徽流、明确保护关系交给狼队友；若不得已接徽，接徽狼次日必须主动切断悍跳视角。
- 若真预首验狼队友，外置查杀很难完全转移轮次。被查杀狼准备表水、拍身份或牺牲口径，其他狼不可全力硬保。
- 悍跳失败、被毒、被放逐或被真预验穿后，立即停止继承其崩盘前提，不再复读遗言硬推查杀位。

## 撤退与切割

- 撤退要分层：一狼具体认错重盘，一狼保留轻疑问，一狼查票型收益，一狼转外置比较。禁止多人同模板“我站错边”。
- 认错必须具体：哪个发言、票型、毒口、验人、守卫日志改变判断；当时为何会信；现在谁从结果获益。
- 切割同伴要切行为链而非表演踩死：说明分歧点、自己为何不同收益、后续如何验证。
- 若队友被验、被毒、被枪，其他狼当天不要同向猛冲同一好人；先分散到两个以上可疑点，等好人归票后再跟进。
- 被清算同票仓时，要比较谁早定调、谁晚跟风、谁承接遗言、谁借归错获益，不能只说“顺票像狼”。

## 白天抗推与伪装

- 每轮至少输出一个可验证判断：今天出谁、备选是谁、差异是什么、若其拍身份怎么处理、出错后明天如何重盘。
- 好用切入口：近全票归错、警徽票与放逐票断裂、承接遗言过快、接徽污染、发言投票不一致、低成本回头、连续顺票、低贡献复读、临票单点。
- 抗推低贡献或复读平民有效，但不能连续多天只推同一套理由。上一轮失败后必须补新证据或更换比较对象。
- 倒钩狼要有独立视角：为何早站真预、为何没有跟狼队票、为何后续更新不是借真预做身份。真预死后转火要提前铺垫。
- 发言前核验公开事实：投票、发言顺序、跳身份时点、警徽流、毒口、守卫日志。终局事实错误会直接失信。
- 多狼同场存活时，话术必须差异化：一个打票型，一个打夜刀收益，一个打身份时点，一个打发言矛盾，避免同模暴露。

## 面对神职与假跳

- 无人对跳的猎人、守卫、女巫若有毒口、平安夜、日志或枪口印证，默认暂放，转打其归票链上的平民。
- 不要白天主推无人对跳明神，除非出该神即可胜利或有完整对跳准备。末狼尤其禁止临时推明猎/明守。
- 假跳猎人、女巫、守卫只能争关键轮次，必须提前铺垫身份视角和夜间信息。临时拍神若不能换到好人或关键白天，通常只会暴露狼。
- 假女巫要解释救药、毒药、站边和为何不毒；假守卫要有完整日志并能解释平安夜；假猎要预判真猎开枪收益并让队友提前切割。
- 真神迟迟不跳时，可短期利用好人暂放心理制造分票；身份壳崩后立即认错切线，不可继续硬保。

## 终局

- 终局前一夜先决定屠神还是屠民。若屠民可成，优先避开明猎和难推明神，刀平民直接结束。
- 末狼至少提前一天铺垫两个以上备选怀疑对象，不能最后一轮突然转推从未提过的人、无人对跳神或强反身份平民。
- 若前期与队友同票同推，必须持续解释当时逻辑、硬信息后的分歧、为何自己不是同收益链，不要等终局才补。
- 最后两轮攻击点要组合使用：票型、夜刀收益、身份时点、改票原因、发言前后矛盾、好人互疑。不要只靠单一“顺票收益”。
- 夜刀不要强化自己的唯一收益链；若某人持续压你，刀他可能坐实你，除非同时能形成更强外置怀疑。
