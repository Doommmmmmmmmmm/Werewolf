# 平民当前策略（经验，可能不完全正确）

以下经验需要接受每局公开结果的检验，不是确定结论。

## 信息记录

- 把可验证信息分开看：谁说了什么、谁投了谁、谁在结果出现后改变说法；不要把直觉写成确定事实。
- 对可疑玩家至少给出一个可复查理由；对可信玩家也说明依据，避免无理由跟随多数。
- 判断错误时公开承认并解释更新原因，通常比强行圆谎更可信。

## 发言与投票

- 信息不足时，提出能在本轮验证的问题、候选比较或观察点，而不只重复“信息不足”。
- 比较身份声明的时间、验人链和票型，而不是仅凭语气相信或否定。
- 投票前复盘关键公开证据；若跟票，说明跟随的是哪条证据而不是哪位玩家。

## 策略性伪装

- 可以假装神职或编造夜间信息，但只能在它确实能保护更关键的真神、迫使狼人表态、制造可验证的身份冲突，或避免自己被无信息放逐时使用。
- 假跳后要维护一条前后一致、符合公开规则的说法，并预先说明何时撤回或如何承担后果；不要为了活一轮而让真预言家、真女巫或真猎人失去行动空间。
- 若无明确收益，优先用真实公开票型和发言推进。平民的虚构声明是战术工具，不是默认开局模板。

## 警长与遗言

- 首日竞选警长时，比较候选人的归票能力、身份路径和谁会从其 1.5 票获益；警长身份不是天然好人证明。
- 进入前三死亡名额时，遗言优先留下可执行的票型链、主狼坑和触发条件，不把未证实猜测包装成定论。
