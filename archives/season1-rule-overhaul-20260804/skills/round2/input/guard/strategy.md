# 角色当前策略（经验，可能不完全正确）

以下经验不能替代行动包中的限制；是否可自守、可否连守、合法目标以引擎请求为准。守卫不会得知是否守中，任何平安夜、单死、双死都不能私自当成确定信息。

## 总原则

- 守卫的价值是：夜里延长关键好人寿命，白天用公开逻辑纠偏投狼；不能只靠夜守期待别人理解。
- 守护目标优先级 = 可信度 × 被刀概率 × 存活收益。三项缺一不可；警徽、发言强势、被多人认好都不是单独保护理由。
- 狼人常用“悍跳预言家拿警徽—推出真预—死后传徽—接徽者继续带票”的链条控场。每昼夜都要检查这条链谁收益最大。

## 首日预言家对跳：先防被骗

- 不因先手查杀、发言格式完整、警徽流顺、给自己金水、拿到警徽就认预言家。
- 首日若出现近全票站某预言家、多人复读同一理由、查杀方票仓过快成型，必须把“大票型异常”列为强狼队信号，而不是只当作共识。
- 判断预言家要同时看：验人逻辑是否闭合、警徽流是否服务视角、归票是否符合身份、票仓是否过齐、对方遗言是否能自洽。
- 即使暂时站边某预言家，也要避免把警徽位当夜间默认保护对象；首夜后若其票型过齐或死后传徽收益过直，应立即降权。

## 女巫毒口与悍跳遗产

- 女巫公开说明某预言家位为毒口后，该人的遗言、金水、查杀、警徽传递先整体降权，必须重盘票型和接徽收益。
- “悍跳狼死了”不等于他是真；死亡可能来自毒药、狼刀做高等，守卫也不防毒。
- 若毒口是悍跳位，下一步优先查：谁继续按其遗言推人、谁接警徽后归好人、谁再把警徽传给下一收益位。
- 接徽者若立刻强推真预金水、女巫、反盘位或低容错好人，应视为高优先级狼坑与低保护目标。

## 夜间守护选择

- 首夜信息少，自守可作为保底，但不要因首夜平安认为自己守中；若已有明显真预/强神高危，可按公开局势改守更高收益目标。
- 真预被放逐后，优先保护：真预金水中能纠偏者、公开反警徽链且逻辑成立者、明女巫、明猎人、能统一好人票的高可信位。
- 不守“可疑警长”。悍跳链传来的警徽、接徽后继续推好人的警徽、被女巫毒口污染的警徽，保护优先级应大幅下降。
- 守中或疑似守中关键位后，下一夜立刻建立第二关键位：同阵营金水、明神、反盘带队者、决定性票位。若不能连守，要预判狼人重复刀与转刀明神两种路线。
- 狼人多次会刀真预金水、明女巫、纠偏位；这些人比“发言最顺的带队位”更值得守。
- 后期人数少时，保护能决定投票方向的共同好人票。若自己并非唯一能改票者，不要机械自守而放任狼人刀掉可信投狼位。
- 当自己是真预金水、少数正确站边者、公开拆警徽链者或即将改变票型的神牌时，提高自守权重；但若不能连守导致次夜无法自保，要提前权衡首夜/前夜自守成本。

## 白天发言与投票

- 隐藏身份时也要给出可复查逻辑：预言家视角、票型、警徽传递、刀口收益、谁在快速制造共识。
- 发现大票型异常时，不只说“保留”，要转化为投票行动：明确要求拆票仓、点出复读位、优先压接徽收益位。
- 女巫报毒或强公开信息出现后，要立即重新排序狼坑；不要继续按毒口遗言、伪金水或污染警徽推进。
- 投票必须与怀疑一致。若已认定警徽链可疑，优先投接徽带票核心，不要分票到低收益位置。
- 站边正确时要主动争多数：给出“今天必须出谁、为什么不是外置位、警徽票会如何影响结果”，避免好人分票被狼队票块压制。

## 公开身份、遗言与日志

- 通常不早跳守卫；但以下情况应强烈考虑跳身份并交日志：自己即将被放逐、生死轮警徽票压制、三狼票块成型、守护日志能解释关键平安或能保护明神/真预金水不被抗推。
- 跳身份时只陈述确定事实：每夜守谁、是否受不能连守限制、守卫不防毒、没有守中确认。不要把“我守了他”说成“他一定好”。
- 若被假查杀且票型仍可反打，可先用逻辑表水；若归票已集中到自己，应及时拍身份，避免守卫白白出局。
- 遗言顺序：守护日志 → 信息边界 → 警徽链/票型狼坑 → 下一轮建议归票。不要把错误站边包装成守卫信息。

## 每轮复盘清单

- 预言家链：谁的验人、警徽流、归票更闭合？谁只靠查杀力度和格式取信？
- 票型链：是否近全票、是否多人复读、谁在关键轮冲票或分票？
- 警徽链：警徽从谁来、传给谁、接徽者推出了谁、再传给谁？连续收益位优先审查。
- 刀口链：狼人刀掉谁的发言能力？谁最怕真预金水、女巫、反盘位活着？
- 守护链：昨夜守过谁，今晚能否连守；若不能，第二关键位是谁，狼人重复刀和转刀各自收益如何？
