# 角色当前策略（经验，可能不完全正确）

## 总目标

- 猎人首先是好人投票位，其次才是临终子弹。不要把胜负押在最后一枪上；白天纠错、拆归票、保护关键好人更重要。
- 子弹公开且不可撤回。开枪目标必须来自多条公开证据叠加，如票型、警徽传递、夜刀收益、身份冲突、连续错误归票，而不是单句发言或个人情绪。
- 信息极少、狼坑未成形时可以跳过；但若已有明确接徽收益链、连续推好人的核心位，应果断开枪。

## 首日站边：口头警惕必须转化为行动

- 不要因预言家发言格式完整、查杀力度大、警徽流漂亮、票数领先，就直接坐实其为真。
- 不要因某预言家给自己金水而放松审查。狼人常给猎人金水来绑定站边。
- 若警徽票或放逐票出现极端单边，要把它当成硬信息处理：谁早定调、谁补票、谁借表水差强推、谁从警徽流受益。
- 首日投票前必须列两套世界：若A是真，狼坑和收益位是谁；若B是真，狼坑和收益位是谁。若只能说出一套，说明自己已被主流绑定，应暂缓跟票。
- 被查杀者表水差只能作为弱证据，不能压过票仓异常、给猎人金水、警徽流收益等结构信息。
- 当你已经指出“票仓过大/警徽过顺/给我金水像绑定”时，不能仍无条件跟随主流。至少要公开提出替代归票，或把票压到最可疑的顺票收益位。

## 警徽、遗言、毒口与夜刀

- 警徽不是天然可信。若警徽来自可能悍跳者，接徽位必须重新审查，不能因持警徽自动获得归票权。
- 悍跳狼死亡后留下的查杀、金水、警徽流、归票遗言都可能是污染信息。每轮都要问：谁靠这条遗产继续获益？
- 女巫毒口、夜死和守卫/其他身份遗言也不能单独决定真伪，但若能证明某悍跳死亡，应立即切断其遗产，不再顺其查杀或警徽流推人。
- 接悍跳狼警徽后若继续归错票、压同一抗推位、再把警徽传给同伴，是最高价值狼点。
- 连续夜刀落在质疑警徽链、质疑接徽位、或可能带队回头的人身上，接徽位及其同向支持者优先进入狼坑。

## 白天发言与投票

- 活着时记录五条线：预言家链、警徽传递、关键票型、夜刀收益、身份声明/无人对跳。
- 发现主流共识形成过快时，必须做反共识检查：推动共识的核心是谁，谁在复读，谁回避更危险的接徽或收益位。
- 怀疑不能只停留在发言。某人满足两条以上狼点时，当轮应明确投票或公开要求其解释收益链。
- 不要因为某人一轮同票、发言顺、短暂回头就直接认好。末轮重点看其前几轮是否救狼、推好人、吃夜刀收益、替污染链拆焦点。
- 若当前归票来自可疑警徽位，要明确提出替代归票，并说明该归票位与警徽链、票型或夜刀的关系。
- 当“发言瑕疵”和“警徽收益链”冲突时，优先审查收益链；不要被单点前后矛盾带偏，放过接徽带队狼。

## 何时拍猎

- 通常不首日主动自曝，但若公开身份能阻止真预或关键好人被近全票冲出，可以强烈考虑拍猎带头要求重盘。
- 以下情况应考虑拍猎：你被查杀且将被推出；你被污染警徽强归；中期好人票型被接徽位控制；末轮或关键轮你的身份能排坑；场上无人对跳身份可重建票型。
- 拍猎后不要只自证。必须立刻给出：当前最疑狼坑、污染警徽/遗言点、当轮归票、若夜死的枪口顺位。
- 无人对跳猎人时，要求场上解释为什么仍要推明猎，谁从推明猎中获益。
- 明猎存活后不要被动等死，要用公开枪口和投票压力逼高嫌疑位交代完整狼坑。

## 开枪前快速清单

死亡触发猎人反应时，快速检查：

1. 目标是否有两类以上证据支持，而非只因发言差或攻击过我？
2. 目标是否接过可能悍跳狼警徽，或持续顺悍跳遗言/假查杀推好人？
3. 目标是否多轮归错票，且每次错误都让同一条污染链获益？
4. 夜刀是否清理了目标的反对者，或让目标获得带队空间？
5. 是否有更核心的接徽狼、带队狼、连续同票抱团位，比低存在感位置更该开？
6. 我的枪口是否只是沿用首日可能错误站边？若是，降低优先级。
7. 目标若是公开神职、无人对跳好身份、或主要在质疑污染链，必须极慎重。

## 枪口优先级

优先开：
- 接可能悍跳狼警徽后连续归错票的位置；
- 多轮顺悍跳遗言、假查杀、污染警徽推动好人出局的位置；
- 夜刀明显压制其反对者后仍持续获益的位置；
- 与已出狼人连续同票、互保、共同压同一抗推位的位置；
- 在你拍猎无人对跳后仍强推明猎的位置。

降低优先级：
- 只因单次措辞差、情绪化或投错一票但后续有清晰回头逻辑的位置；
- 主要在质疑警徽污染、保护可能真预或神职、推动重盘的位置；
- 证据不足且可能是关键好人身份的位置。

## 死亡遗言与不开枪

- 不开枪可以是正确选择，但必须留下具体审查顺位，不能只说“重盘警徽”。
- 遗言至少给出三项：最可疑接徽/收益位、其同向帮手、如果该位出局不终局下一层看谁。
- 若白天主嫌已出局，必须立即更新夜死枪口顺位，避免枪口停留在已死亡目标或遗漏真实狼位。

## 末轮与残局

- 末轮不要只看谁发言自然。重点看：谁救过狼、推过好人、从夜刀中获益、在关键票上拆好人票。
- 明猎残局要把自己作为公共好人约束，逼其他人给出完整狼坑和票型解释。
- 开枪命中一狼也可能太晚无法翻盘，所以越早把可疑警徽链、悍跳遗产链转成白天投票，胜率越高。
