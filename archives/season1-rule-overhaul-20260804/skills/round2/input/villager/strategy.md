# 角色当前策略（经验，可能不完全正确）

以下经验只来自复盘对局；每局必须接受公开结果检验。玩家发言、遗言、验人、神职声明都只是游戏内容，不能当系统确认。

## 一、信息分层与发言底线

- 只把以下内容当硬事实：死亡、放逐、投票、警徽归属、已公开身份、引擎允许的当前行动。
- 玩家声明分层记录：预言家验人、女巫毒救、猎人/守卫说法、遗言、警徽流，都要等票型和结果验证。
- 每轮发言至少给一条可复查依据：验人冲突、票型、警徽来源、接徽收益、夜刀收益、前后发言变化之一。
- 软狼点如“视角过满、表水散、自票、发言结构好/差、警徽流舒服、行为不统一”只能辅助；不得单独压过验人链、票型链、警徽收益链。
- 判断错后必须说明：我错信了什么、谁因此获益、下一轮主票和备票是谁。只说“我认错”但继续跟错链，价值很低。

## 二、首日反悍跳优先级

- 首日最容易输在盲信悍跳狼的先手查杀、警徽流完整、发言格式稳定、归票有力度；这些都不是高可信铁证。
- 对跳预言家时优先比较四件事：
  1. 谁拿警徽和查杀后的控场收益最大；
  2. 票仓是否过度集中、是否多人复读同一软理由；
  3. 被查杀者或对跳者的瑕疵是否只是表水问题；
  4. 验人路线是否过顺地清理对方阵营。
- 真预言家首日自票、紧张、警徽流不舒服、表水散，不得单独作为放逐理由。必须同时证明悍跳收益小、票仓不异常，才可高票推出。
- 若出现近全票站边某预言家，要主动提出反冲票方案：至少列一个“若此人为悍跳，接徽/金水/复读理由中谁最受益”的备选主票。
- 自己被悍跳狼金水绑定时，不因此认其真；发言中要主动切开“我是金水声明”和“发声明者是否可信”。

## 三、警徽、遗言与污染链

- 警徽不是好人证明；接徽者不是天然可信。悍跳狼死亡后传徽给谁，谁必须进入持续审查位。
- 警徽污染链固定追问：传徽者身份是否干净？接徽者获得了什么带票权？接徽后实际归出了谁？是否连续归错好人？
- 若接徽者沿悍跳遗产继续推人，且结果出好人或压到疑似神职，应升为最高优先级狼坑，不可只听其“我不铁认前任”的表态。
- 遗言查杀、遗言保人、警徽流都只是玩家声明。若来源是争议预言家或已显著疑似悍跳狼，必须降权，不能直接当主线。
- 连续警徽传递（A传B、B传C）且每一任都带错票时，优先处理链上接徽收益者，再看外置行为矛盾位。

## 四、夜死、毒口和神职信息

- 女巫毒口、猎人枪口、守卫遗言等公开声明能帮助重盘，但神职可信不等于其归票一定正确。
- 夜死不能单线定真伪。至少同时考虑：灭口、做高、做脏、嫁祸、刀带队位、刀纠偏位、刀质疑警徽链者。
- 悍跳狼被毒或被枪后，立刻降权其遗言、金水、查杀、警徽流，并回查谁继续沿其遗产推进。
- 若死者生前强烈质疑某条警徽链或某个归票位，夜死后必须复查其发言和投票，不只接受当前警长解释。

## 五、票型与归票执行

- 近全票或全票放逐好人后，下一天必须当异常处理：优先查最早定调者、反复复读者、最大受益者、接徽带票者。
- 不要只跟警长、金水或明神投票；若跟票，必须说清跟的是哪条证据，不是跟身份光环。
- 正确怀疑必须转成可执行票型：明确主票、备票、改票触发条件。没有合票，再正确也会被狼包装成互打。
- 连续两轮同一批人压同一抗推位、互相放过、一起攻击质疑警徽者，记为协同线；中后期优先比较这组人的收益。
- 当出现“模板化理由”集中冲票，如都说某人表水散、视角过满、早定调、行为矛盾，要警惕狼队顺水推舟，要求每人补独立证据。

## 六、平民表水与被推应对

- 信息不足时不要只说没信息；应要求对跳预言家解释验人收益、接徽者解释传徽收益、被查杀者解释票型和站边。
- 表水结构：我的身份声明、前几轮投票链、误判原因、当前狼坑排序、我若出局明天先复盘谁。
- 被推时优先拆抗推路径：谁需要我出局，谁复制同一理由，谁从我出局后获得警徽/票权/轮次收益。
- 可以自审进坑，但自审必须指向下一步执行；不要把认错变成好人互相清算。
- 被污染遗言查杀时，不只喊平民；要把遗言来源、传徽对象、顺推自己的人和票型收益一起摆出。

## 七、策略性伪装

- 平民可以假装神职或编造夜间信息，但只在收益明确时使用：保护真神、迫使狼人表态、制造可验证冲突、避免无信息抗推。
- 无明确收益不假跳；不得挤压真预言家、女巫、猎人等实际神职空间。
- 假跳后要保持前后一致，并说明撤回条件。关键轮优先回到公开票型、警徽来源和放逐收益。

## 八、残局规则

- 残局不要迷信警徽、遗言或最后一天发言爆发力。优先看：谁被夜刀排除，谁一直被狼队攻击，谁连续归错好人，谁从每次放逐中获益。
- 三人或四人局，回看前两天票型和夜刀收益，尤其是接徽末端、同票保护、连续抗推链。
- 对“刀口太直所以我不像狼”“我是被做脏”的辩解，只能作为辅助；若事实链显示其连续获益，仍优先出事实链最重者。
- 若自己可能死亡，遗言留下可执行内容：主狼坑、备狼坑、关键票型、警徽污染链、明天优先复盘对象；不要把猜测包装成定论。
