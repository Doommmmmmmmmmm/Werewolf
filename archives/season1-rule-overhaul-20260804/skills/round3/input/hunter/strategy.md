# 角色当前策略（经验，可能不完全正确）

## 总目标

- 猎人首先是好人投票位，其次才是临终子弹。优先用白天发言、投票和身份排坑帮助好人放逐狼人，不要把胜负押在最后一枪。
- 枪口公开且不可撤回。开枪必须有两类以上公开证据叠加：验人/身份冲突、票型、警徽传递、夜刀收益、连续错误归票、悍跳遗产收益。禁止只因发言差、攻击过我、单次站错就开枪。
- 任何信息都要分层：已公开死亡和验人链闭合的信息 > 无人对跳神职及其可验证毒口/守护逻辑 > 票型和夜刀收益 > 警徽/遗言/发言观感。低层信息不能单独压过高层信息。

## 首日站边与投票

- 首日必须列两套世界：若A是真预，狼坑、查杀收益、警徽流收益是谁；若B是真预，同样列出。若只能列一套，说明自己可能被主流绑定，应暂缓跟票。
- 不因发言格式完整、查杀力度大、票数领先、给我金水就直接坐实预言家；狼人常用查杀、金水和漂亮警徽流控票。
- 也不能只因“警徽票过顺”就推翻真实验人结构。投票前必须同时比较：谁的验人收益更直、谁的警徽流压质疑者、谁的票仓异常、谁被查杀后的表水是否能闭合。
- 被查杀者表水差是弱证据；悍跳收益、票仓抱团、身份冲突和验人链是强证据。
- 当已指出票仓异常或警徽污染时，必须转化为行动：公开替代归票、要求核心位解释收益链，或把票压到最可疑的顺票收益位。不要只口头反共识、投票仍近全票跟随。
- 若出现无人对跳神职跳出，要先记录为较高权重但不盲信：要求其说明毒口/救人/视角来源，并检查是否与验人链、双死、夜间结果冲突。

## 警徽、遗言、毒口与夜刀

- 警徽不是天然可信。若警徽来自可能悍跳者，接徽位必须重新审查；若警徽来自较可信真预，也要防倒钩和利用警徽流制造近全票抗推。
- 悍跳狼死亡后留下的查杀、金水、警徽流、归票遗言都可能是污染信息。每轮问：谁靠这条遗产继续获益？谁把遗言和半可信信息叠成“必出”？
- 女巫毒口、双死、夜刀不能单独决定一切，但若毒口与预言家验人、票型或死亡信息闭合，权重要高于争议遗言和票仓观感。
- 连续夜刀落在质疑警徽链、主审接徽位、或可能带队回头的人身上，夜刀收益位和其同向支持者要进核心狼坑。
- 接悍跳狼警徽后若继续归错票、压同一抗推位、再传徽给同向位，是高价值狼点；但开枪前仍要排除其是否有真实验好或无人对跳神职支撑。

## 白天发言与投票

- 活着时固定记录五条线：预言家链、警徽传递、关键票型、夜刀收益、身份声明/对跳情况。
- 发现共识过快或近全票时，必须做反共识检查：首置定调者是谁，谁复读，谁借表水差强推，谁回避更危险的接徽/收益位。
- 怀疑不能停在发言。某人满足两条以上狼点，当轮应明确投票或要求其解释完整狼坑、前后票型和夜刀收益。
- 不要因为某人认错回头、投过一狼、发言自然就直接认好。重点看纵向：是否先站悍跳、后顺主流、每轮错误都让自己安全或让同一污染链获益。
- 当“发言瑕疵”和“长期票型收益”冲突时，优先审查长期收益。末狼常靠顺势认错、跟真预出狼、再在关键轮转推好人隐藏。
- 若当前归票来自可疑警徽位或接徽位，要给出替代归票，并说明该位与警徽链、票型、夜刀或悍跳遗产的关系。

## 何时拍猎

- 通常不首日主动自曝，但若公开身份能阻止真预、明神或关键好人被近全票冲出，可以强烈考虑拍猎。
- 以下情况应优先拍猎：我被查杀且即将出局；我被污染警徽强归；真预/女巫等核心身份把我推到高危且我无法用发言拆票；中后期好人票型被接徽位控制；末轮我的身份能排坑；有人悍跳猎人。
- 拍猎后不要只自证，必须立即给出：最疑狼坑、污染警徽/遗言点、当轮归票、若夜死的枪口顺位。
- 无人对跳猎人时，要求场上解释为什么仍要推明猎，谁从推明猎中获益。明猎要用枪口压力逼高嫌疑位交代全程票型，而不是被动等死。
- 有人悍跳猎人时，果断对跳，围绕身份冲突归票；同时保留其同伴是否借对跳乱票的记录。

## 开枪前快速清单

死亡触发猎人反应时，快速检查：

1. 目标是否有两类以上硬证据，而非只因单句发言、情绪或攻击我？
2. 目标是否接过可能悍跳狼警徽，或持续顺悍跳遗言/假查杀推好人？
3. 目标是否多轮归错票，且每次错误都让同一条污染链或自己安全获益？
4. 夜刀是否清理了目标的反对者，或让目标获得带队空间？
5. 是否有更核心的带队狼、连续同票抱团位、悍跳同向位，比低存在感位置更该开？
6. 我的枪口是否只是沿用首日可能错误站边或“票仓过顺”印象？若是，必须降级。
7. 目标若可能是真预、无人对跳神职、被可信毒口/验人链支持，或主要在质疑污染链，原则上不开，除非有身份冲突或更高层证据推翻。

## 枪口优先级

优先开：
- 接可能悍跳狼警徽后连续归错票、压同一抗推位的位置；
- 多轮顺悍跳遗言、假查杀、污染警徽推动好人出局的位置；
- 夜刀明显压制其反对者后仍持续获益的位置；
- 与已出狼人连续同票、互保、共同压同一抗推位的位置；
- 在我拍猎无人对跳后仍强推明猎的位置；
- 白天难以推出、但行为链完整的隐蔽同向狼。若接徽核心已能被白天处理，枪可考虑打其更隐蔽帮手。

降低优先级：
- 只因单次措辞差、情绪化或投错一票，但后续有清晰回头和实际纠错行动的位置；
- 主要在质疑警徽污染、保护可能真预或推动重盘的位置；
- 公开神职、无人对跳好身份、被可信验人/毒口支持的位置；
- 证据不足且可能是关键好人身份的位置。

## 遗言与不开枪

- 信息不足、目标证据不够或可能误杀核心好人时，可以不开枪；不开枪必须留下具体审查顺位。
- 遗言至少给出三项：最可疑接徽/带队/收益位，其同向帮手，如果该位出局不终局下一层看谁。
- 若白天主嫌已出局或我的站边被新信息推翻，必须立即更新枪口顺位，避免子弹停留在旧印象。
- 枪中一狼后也要提醒好人继续追：谁与其同票，谁靠其死亡切割，谁在残局转移焦点。

## 末轮与残局

- 末轮不要只看谁发言自然。重点看：谁救过狼、推过好人、从夜刀中获益、在关键票上拆好人票、认错后是否仍安全获益。
- 明猎残局要把自己作为公共好人约束，要求每名玩家解释全程票型、夜刀收益和完整狼坑。
- 开枪命中一狼也可能太晚无法翻盘，所以越早把可疑警徽链、悍跳遗产链、顺势认错链转成白天投票，胜率越高。
