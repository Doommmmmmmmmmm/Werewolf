# 角色当前策略（经验，可能不完全正确）

以下经验不能替代行动包限制；是否可自守、可否连守、合法目标以引擎请求为准。守卫不会得知是否守中，平安夜、单死、双死都不能私自当成确定信息。

## 总原则

- 守卫目标价值 = 可信度 × 被刀概率 × 存活收益。
- 三项缺一不可；警徽、发言强势、被多人认好，都不是单独保护理由。
- 夜里优先延长“能改写白天票型的人”的寿命，白天必须用票型、警徽链、刀口收益去纠偏。
- 狼人常用“悍跳/假身份—大票仓—警徽或遗言传递—接续抗推”控场。每轮都要检查谁从这条链继续获益。

## 首夜原则

- 首夜不机械自守。
- 若无明显高危目标，自守可以保底；若场上已有更高价值的真预、明女巫、明猎人、被悍跳查杀的强好人、或能带队纠偏的关键位，优先外守。
- 不要因为先手查杀、发言格式、警徽流完整、拿警徽、给自己金水，就直接认预言家。
- 若首日出现近全票站边、多人复读同一理由、查杀方票仓过快成型，这通常是强狼队信号，白天就要开始拆票仓，而不是等夜里补救。

## 夜间守护优先级

- 真预仍在场且大概率被刀时，优先守真预。
- 已经守过真预、且不能连守时，必须提前选“第二关键位”。优先级通常为：
  1. 真预金水 / 接徽且能带队的真好人
  2. 明女巫 / 明猎人
  3. 公开反悍跳、且逻辑成立的纠偏位
  4. 能形成共同好人票的关键位
  5. 自己
- 若狼人显然知道你不能连守，要同时预判两条线：重复刀真预，或转刀金水 / 女巫 / 纠偏位。
- 不要把“守过真预一次”理解成“后面只要继续守关键神就一定赚”。重复刀和转刀都会发生。
- 女巫毒药不受守卫影响；即使守对了人，也要考虑该人是否可能被毒、或是否会因公开身份而更值得保护。
- 后期人数少时，优先保护能决定归票方向的共同好人票。若自己不是唯一能改票的人，不要机械自守。

## 白天发言与投票

- 隐藏身份时，也要给出可复查逻辑：预言家视角、票型、警徽传递、刀口收益、谁首置定调、谁复读、谁跟票保命。
- 怀疑必须转化为投票行动。发现大票仓异常时，要明确要求拆票仓，优先压首置带节奏位、接续归票位、关键轮跟票获益位。
- 女巫报毒、真假身份结果出现后，立即重排狼坑；毒口遗言、金水、查杀、警徽传递整体都要降权，但不能无脑全打死。
- 投票必须与发言一致。关键轮不能口头主票一人、实际却投无人或分票。
- 近全票推出好人时，重点审首置定调者、复读者、跟票保命者，不要只盯最后归票的人。
- 末狼判断不要只看谁连续带错票，要比较谁在关键轮低成本跟票、谁被夜刀结构保护、谁从女巫/金水/纠偏位死亡中获益。

## 跳守卫与日志

- 通常不早跳守卫；但以下情况应强烈考虑跳：
  - 自己即将被放逐；
  - 真假守卫轮；
  - 自己接警徽且进入备审；
  - 三狼票块成型；
  - 末轮身份坑混乱；
  - 需要用日志解释关键平安夜或保护明神 / 真预金水的收益。
- 跳身份只陈述确定事实：每夜守谁、是否受不能连守限制、守卫不防毒、没有守中确认。
- 若被假查杀但票型仍可反打，可先用逻辑表水；若归票已集中到自己，应及时拍身份。
- 遗言 / 公开顺序建议：守护日志 → 信息边界 → 票型和警徽链狼坑 → 刀口收益 → 下一轮建议归票。

## 每轮复盘清单

- 预言家链：谁的验人、警徽流、归票更闭合？谁只靠查杀力度、格式或身份叙事取信？
- 票型链：是否近全票？谁首置定调、谁复读、谁关键轮冲票或分票、谁跟票保命？
- 警徽链：警徽从谁来、传给谁、接徽者推出谁、再传给谁；连续收益位优先审查。
- 刀口链：狼人刀掉谁的发言能力和票权？谁最怕真预、金水、女巫、纠偏位活着？是否在用刀口制造抗推？
- 守护链：昨夜守谁，今晚能否连守；若不能，第二关键位是谁；狼人重复刀与转刀各自收益如何？

## 关键修正规则

- 不要让“真预像不像”压过“谁是当前最能改票的好人”。
- 成功守住真预一夜后，第二夜的核心不是“继续找最像真预的人”，而是“找狼人最想立刻处理的第二收益位”。
- 如果场上已经出现明女巫、明猎人、接徽且能带队的真好人，且其公开信息能改变白天投票，保护优先级应高于普通争议位。
- 守卫没有守中确认，所以任何守护收益都要和白天票型一起看；只要白天继续跟错票，夜守收益可能被抵消。
