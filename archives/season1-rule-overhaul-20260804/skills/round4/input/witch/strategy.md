# 角色当前策略（经验，可能不完全正确）

以下策略只来自近期复盘，是可修正经验，不是绝对规则。目标是用两瓶药最大化好人轮次，并把夜间信息转化为白天可接受的公开逻辑。

## 总原则

- 女巫是好人纠偏位：首夜优先防减员，中期用毒处理高交叉印证狼位，白天负责拆狼人叙事并组织归票。
- 药水余量、刀口、夜间行动默认保密；但当毒口信息能阻止好人继续沿错误遗言/警徽链放逐，或自己将被抗推时，应主动跳明。
- 公开发言尽量只用公开事实：预言家对跳、警徽流、投票、遗言收益、谁接徽、谁继续推进同一抗推线、谁因某个结论获利。

## 解药使用

- 首夜被刀者若无明显公开爆狼行为，通常倾向使用解药；若自己被刀，应自救保住行动能力。近期10局首夜救人/自救均带来正收益。
- 救人后不要主动报刀口或银水；被救者只能作为私下偏好，不能公开当铁好。
- 后续若被救者发言、票型、身份行为变差，应允许回盘，不因救过而强保。

## 首日预言家对跳防带偏

- 近期最大漏洞是首日连续站错边。先手查杀、发言完整、拿警徽、票型大，不等于真预。
- 出现以下情况必须降权悍跳方，至少保留回头空间：
  - 警徽票或放逐票过于单边，狼人几乎无需反抗；
  - 悍跳者警徽流、归票、遗言都服务同一抗推链；
  - 接查杀起跳、强查杀力度带动全场，但缺少可回验逻辑；
  - 所谓金水/接徽位只复读预言家权威，缺少独立找狼；
  - 真预被冲时，反对声音少且被迅速污名化。
- 首日若无法确认真假，不要把另一边所有站边者一次性打死；记录双方验人、警徽流、归票者、弃票/分票者和谁获利。
- 发现“九票、十票、近全票”这类极端共识时，要公开提出风险并要求关键位表态；必要时考虑分票或至少留下回盘理由。

## 毒药使用

- 毒药优先给多线交叉印证的狼位，不给单点讨厌位。可用证据包括：
  - 悍跳预言家，尤其在真预被高票推出后仍掌警徽和遗言权；
  - 警徽流、验人、归票与狼队收益高度一致；
  - 票型过齐地冲出真预、金水或关键好人；
  - 多名可疑位互相保护、同向攻击同一好人坑；
  - 死后传徽能明显让某人继续接力带队。
- 真预首日被推出后，夜里毒杀悍跳狼通常价值很高；但毒后必须准备白天说明：为什么夜死者不是被刀真预，而是我的毒口，以及哪些公开证据支持其为狼。
- 不要只因某人攻击自己、强势或站错边就毒；至少需要发言、票型、警徽/身份链中的两类证据互相支撑。

## 毒中悍跳狼后的跳明原则

- 若毒口是对跳预言家、接警徽核心、被真预查杀狼，且场上可能继续吃其遗言，应优先跳女巫公开“昨夜某人是我的毒口”。
- 跳明时不要只靠身份压人，应同步给出公开逻辑：
  - 毒口生前警徽流、验人、归票如何服务狼队；
  - 谁首日强站边、谁死后继续吃遗产；
  - 毒口把警徽交给谁，接徽者是否继续推进同一假链；
  - 真预遗言、被查杀者反应、首日票型如何解释毒口为狼。
- 若自己首日曾站错边，必须主动解释转变依据：承认早期判断错，用毒口、票型过顺、警徽收益和遗言矛盾说明为何回头。
- 跳明后当天必须留下遗产：主票1人、备票1-2人、若主票出错第二天先审谁，避免夜死后好人失去方向。

## 毒后白天归票优先级

- 毒中悍跳只解决预言家真假，不自动找齐狼坑。归票按以下顺序综合判断：
  1. 接毒口警徽且继续推进毒口遗产的人；
  2. 毒口死后仍把其夜死当真预、强推假查杀的人；
  3. 首日大票冲真预、次日仍不回盘或解释空洞的人；
  4. 核心压力位中当日逃避发言、跳过表水、突然改口切割的人；
  5. 与上述位置连续同票、互保、同向攻击同一好人的人。
- 不要只因“吃遗产”“票顺”“发言同质”就近全票推出一人；必须再看其是否真的从假预链获利，是否有当日爆狼行为，是否可能是被狼顺水推的好人。
- 接徽位即使回头发言好，也不能立刻放下；要看其归票结果、是否继续占票权、是否把责任转移给无警徽收益的好人。
- 当场上好人纠偏方向与自己不同，要重听后置发言和临场行为；若多数好人都转向某个压力位，先判断是否有新的逃避、爆点或票型信息，不要机械坚持旧票仓。

## 白天发言模板

- 每轮至少给出：最像狼的1-2人、理由、备选坑位、暂不处理的人及原因。
- 被攻击时先自保再找狼：说明自己判断变化的公开依据，指出攻击你的人如何同步、谁从你出局中获利。
- 若归票过于一致，要追问：狼人为什么不反抗？这次放逐是否正好延续毒口的警徽/遗言链？
- 明女巫无药后不要沉默等死；身份价值在于整合好人票、公布毒口、压缩狼坑和留下清晰遗产。

## 常见狼队叙事反制

- “夜死预言家所以真”：先说明可能是女巫毒口，再看其生前警徽流、票型和谁接遗产。夜死不能单独定真。
- “接警徽就是好人”：警徽只说明死者选择，不说明阵营。重点看接徽者是否继续推动狼队收益。
- “女巫回头太快像狼”：承认首日可能站错，用毒口、票型过顺、警徽链和真预遗言解释回头。
- “某人票顺所以先出”：票顺只是线索，不是结论；还要看警徽收益、当日发言、互保关系和放逐收益。

## 自我校验清单

- 我是否又被查杀力度、警徽权威、金水或大票型带偏？
- 预言家对跳票型是否过顺，狼人是否几乎没有反抗？
- 准备毒的人是否至少有两类公开证据支撑？
- 毒后若不跳明，场上是否会继续吃假遗言或假警徽？
- 跳明后我的主票是否同时满足警徽收益、票型、发言/当日行为中的多项证据？
- 接毒口警徽的人是否被持续审查，而不是因回头发言被过早放下？
- 若我今晚被刀，场上是否知道明天先审谁、为什么审？
