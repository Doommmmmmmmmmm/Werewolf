# 角色当前策略（经验，可能不完全正确）

以下经验不能替代行动包限制；是否可自守、可否连守、合法目标以引擎请求为准。守卫不会得知是否守中；平安夜、单死、双死都不能私自当成确定信息。

## 总原则

- 守护目标价值 = 可信度 × 被刀概率 × 存活收益。
- 可信度、被刀概率、存活收益缺一不可；警徽、发言强势、被多人认好，都不是单独保护理由。
- 夜里优先延长“能改变白天票型的人”的寿命；白天必须用票型、警徽链、刀口收益把夜守收益转化为正确放逐。
- 狼人常用“悍跳/假身份—大票仓—警徽或遗言传递—接续抗推”控场。每轮都要检查谁从这条链继续获益。
- 守卫最怕白天跟错票：即使夜里守中，若白天近全票推出好人，收益也会被抵消。

## 首夜原则

- 首夜不默认自守。自守只是保底选项，不是固定答案。
- 若首日已有高危真预、明女巫、明猎人、被悍跳查杀的强好人、接近共识的纠偏位，优先外守。
- 若自己白天明显成为狼队刀口：强发言带队、被多人认好、接近公共好人、被狼阵营威胁，才提高自守权重。
- 不要因为先手查杀、格式完整、警徽流漂亮、拿警徽、给自己金水，就直接认定某预言家为真。
- 若首日出现近全票站边、多人复读同一理由、查杀方票仓过快成型，白天必须开始拆票仓，夜里也要警惕真预或被抗推好人被刀。

## 夜间守护优先级

- 真预仍在场且大概率被刀时，优先守真预；真预被守住一夜能多出验人和遗言，是高收益守护。
- 明女巫、明猎人、真预金水、接徽且能带队者、公开反悍跳且逻辑成立的纠偏位，通常高于普通争议位。
- 后期人数少时，优先保护能决定归票方向的共同好人票；若自己正是唯一能改票或能报日志的人，自守权重上升。
- 女巫毒药不受守卫影响。若自己被女巫或公共好人严重怀疑，夜里守女巫不能防止被毒，白天更应考虑及时跳守卫报日志。

## 不能连守后的判断

- 成功守住真预或关键位后，下一夜是最高风险节点。狼人常见两种打法：
  1. 利用不能连守重复刀原关键位；
  2. 转刀金水、接徽者、女巫、猎人、强纠偏位或守卫本人。
- 不能连守时不要机械找“第二关键位”，要同时比较：原目标若倒牌谁获益、第二目标若倒牌谁获益、自己若倒牌日志是否丢失。
- 若首夜自守挡刀或自己已明显被狼队点名，下一次离开自守前必须评估“狼人回刀守卫本人”的概率；不要因找到外置关键位就忽视自身仍是刀口。
- 若真预被守后仍掌握关键验人或警徽流，白天要最大化其新增信息；即使夜里无法连守，也要用票型提前锁定狼坑。

## 白天发言与投票

- 隐藏身份时，也要给出可复查逻辑：预言家视角、票型、警徽传递、刀口收益、谁首置定调、谁复读、谁跟票保命。
- 怀疑必须转化为投票行动。发现大票仓异常时，要明确要求拆票仓，优先压首置带节奏位、接续归票位、关键轮跟票获益位。
- 近全票推出好人或真预后，重点审：最早定调者、复读同一理由者、低成本跟票保命者、接徽后继续错误归票者，不要只盯最后归票的人。
- 女巫报毒、猎人开枪、真假身份结果出现后，立即重排狼坑；毒口、金水、查杀、警徽传递都要结合来源降权或增权，不能无脑全信或全打死。
- 投票必须与发言一致。关键轮不能口头主票一人、实际投无人或分票。
- 末狼判断不要只看谁连续带错票，要比较谁在关键轮低成本跟票、谁被夜刀结构保护、谁提前解释平安夜或铺垫“狼刀狼”。

## 跳守卫与日志

- 通常不早跳守卫，但以下情况应强烈考虑立即跳：
  - 自己即将被放逐或已成为主归票；
  - 被女巫、金水、接徽带队位强烈怀疑，存在被毒或被强推风险；
  - 真假守卫轮；
  - 自己接警徽且进入备审；
  - 三狼票块成型、无对跳却持续压你；
  - 末轮身份坑混乱；
  - 需要用日志解释关键平安夜、保护明神、保护真预金水或接徽位的收益。
- 跳身份只陈述确定事实：每夜守谁、是否受不能连守限制、守卫不防毒、没有守中确认。
- 被假查杀但票型仍可反打，可先用逻辑表水；若归票已集中到自己，不要贪隐藏，及时拍身份。
- 公开顺序建议：守护日志 → 信息边界 → 哪些死亡不是守卫能防的 → 票型和警徽链狼坑 → 刀口收益 → 下一轮建议归票。
- 无对跳守卫后，仍强压真守的人要重点进狼坑；但不要只靠“无人对跳”躺赢，仍需用票型验证。

## 每轮复盘清单

- 预言家链：谁的验人、警徽流、归票更闭合？谁只靠查杀力度、格式或身份叙事取信？
- 票型链：是否近全票？谁首置定调、谁复读、谁关键轮冲票或分票、谁跟票保命？
- 警徽链：警徽从谁来、传给谁、接徽者推出谁、再传给谁；连续收益位优先审查。
- 刀口链：狼人刀掉谁的发言能力和票权？谁最怕真预、金水、女巫、纠偏位活着？是否在用刀口制造抗推？
- 守护链：昨夜守谁，今晚能否连守；原目标、第二目标、自己分别被刀的收益如何？狼人是更可能重复刀、转刀，还是回刀守卫？

## 关键修正规则

- 不要让“真预像不像”压过“谁是当前最能改票的好人”。
- 首夜自守不能机械化；有公开高危关键位时，外守通常更有上限。
- 成功守住真预一夜后，必须同时准备两套方案：白天用新增信息强推狼坑；夜里预判重复刀与转刀。
- 若自己进入焦点，日志本身就是好人信息资产；该跳不跳导致守卫出局或被毒，往往比暴露身份更亏。
- 守卫没有守中确认，所以任何夜间判断都要回到白天票型验证；平安夜只能提供线索，不能单独定义铁好或铁狼。
