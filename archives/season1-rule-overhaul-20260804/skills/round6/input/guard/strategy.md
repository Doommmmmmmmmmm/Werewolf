# 角色当前策略（经验，可能不完全正确）

以下经验不能替代引擎行动包；是否可自守、能否连守、合法目标以当夜请求为准。守卫不会获得守中确认；平安夜、单死、双死都只能作为线索，不能单独定义铁好或铁狼。

## 总原则

- 守护目标价值 = 可信度 × 被刀概率 × 存活收益。三项缺一不可。
- 白天投票比夜守同样重要：守中一夜若白天近全票推出真预或好人，收益会被抵消。
- 狼队常用链条：悍跳预言家 → 大票仓/近全票 → 污染警徽或遗言 → 接续抗推。每轮都要审谁持续获益。
- 不因警徽、格式、查杀力度、强势发言、给自己金水而直接认真预；必须结合票型、视角闭合度和收益链。
- 守卫日志是信息资产。隐藏身份时要用逻辑贡献；身份价值高于隐藏收益时要及时公开。

## 首夜守护

首夜不要机械自守，也不要随意外守普通位。按以下顺序比较：

1. 高可信真预或被悍跳查杀的强好人，且狼队有明显刀掉其信息的收益。
2. 明女巫、明猎人、已被多人认可且能纠偏的公共好人。
3. 自己：当自己强势带队、被多人认好、明显被狼威胁，或首日发言已让自己成为高刀口时，提高自守权重。
4. 其他外置位必须同时满足“可信、可能被刀、活着有收益”，否则不如守核心或自守。

首日若出现近全票站边、多人复读同一理由、查杀方票仓过快成型，白天就要拆票仓；夜里优先考虑真预、被抗推好人或自己是否会被刀。

## 夜间守护优先级

- 真预仍在场且大概率被刀时，通常优先守真预。守真预一夜的收益是新增验人、遗言和票型校正。
- 明女巫、明猎人、真预金水、能接管归票的公共好人、公开反悍跳且逻辑成立的纠偏位，优先级高于普通争议位。
- 接污染警徽者要降权：若警徽来自悍跳狼或错误链，接徽者只有在独立发言、票型和收益都明显做好的情况下才值得守。
- 不守低可信预言家、假预遗言受益者、连续错误归票且解释不闭合者；这些位置即使有警徽也可能是狼队保护伞。
- 女巫毒药不受守卫影响。若自己被女巫或公共好人严重怀疑，守女巫不能防毒，白天应优先解释或跳身份。

## 守中关键位后的处理

- 守卫没有守中确认，但若出现平安夜且守护目标是高危真预/明神/公共核心，应把它当作强线索而非铁证。
- 守中真预或关键位后，下一夜是最高风险节点。狼人很常见会：
  1. 利用不能连守重复刀原核心位；
  2. 转刀真预金水、女巫、猎人、接管归票者；
  3. 回刀守卫本人。
- 不能连守时，不要机械找“第二关键位”。必须比较三件事：原目标若倒牌谁获益、第二目标若倒牌谁获益、自己若倒牌日志是否丢失。
- 若规则导致无法继续守真预，白天必须提前最大化真预新增验人、警徽流和票型价值，尽量在真预被补刀前推出狼。
- 若自己曾可能是女巫救起的首刀，或已经被狼人点名，离开自守前要认真评估狼队续刀守卫的概率。

## 白天发言与投票

- 隐藏身份时也要给可复查逻辑：预言家视角、票型、警徽传递、刀口收益、谁首置定调、谁复读、谁跟票保命。
- 发现大票仓异常，要明确拆票仓，优先压首置带节奏位、接续归票位、低成本跟票位和关键轮分票救狼位。
- 真预或好人被近全票推出后，重点审：最早定调者、复读同一理由者、低成本跟票者、接徽后继续错误归票者；不要只盯最后一票。
- 假预遗言、毒口、查杀、警徽流都要按来源降权或增权。悍跳狼的遗产不能无脑继承。
- 明女巫报毒、猎人开枪、真假身份结果出现后，立即重排狼坑；旧站边要服从新票型和收益链。
- 投票必须与发言一致。关键轮不能口头主票一人、实际投另一人或分票。怀疑必须转化为投票行动。
- 末狼判断优先看关键轮收益：谁救狼、谁不跟公共预案、谁持续抗推无人对跳神、谁被夜刀结构保护。

## 跳守卫与日志

通常不早跳，但以下情况应强烈考虑立即跳：

- 自己成为主归票或票压集中；
- 自己拥有能解释关键平安夜、真预多活一夜、明神存活的日志；
- 被女巫、金水、接徽带队位强烈怀疑，有被毒或强推风险；
- 真假守卫轮、末轮身份坑混乱、三狼票块明显压自己；
- 自己接警徽进入备审，或日志若随自己出局会严重损失信息。

跳身份时只报确定事实：每夜守谁、受何种不能连守限制、守卫不防毒、没有守中确认。推荐顺序：守护日志 → 信息边界 → 哪些死亡不是守卫能防 → 票型和警徽链狼坑 → 刀口收益 → 今日归票建议。

无人对跳守卫后，仍强压真守的人重点进狼坑；但不要只靠无人对跳躺赢，仍要用票型和收益验证。

## 每轮复盘清单

- 预言家链：谁的验人、警徽流、归票更闭合？谁只靠查杀力度或格式取信？
- 票型链：是否近全票？谁首置定调、谁复读、谁冲票、谁分票、谁跟票保命？
- 警徽链：警徽从谁来、传给谁、接徽者推出谁；来自悍跳狼的警徽链默认降权审查。
- 刀口链：狼人刀掉谁的发言力和票权？谁最怕真预、女巫、金水、纠偏位活着？是否在用刀口制造抗推？
- 守护链：昨夜守谁，今晚能否连守；原目标、第二目标、自己分别被刀的收益如何？狼人更可能重复刀、转刀还是回刀守卫？

## 关键修正规则

- 首夜少守普通位；优先比较真预/明神/公共核心/自己四类高收益目标。
- 守中核心位后，默认狼队有较高概率重复刀；白天必须先把新增信息转成归票。
- 污染警徽链不是保护理由，反而是审查理由。
- 自己进入焦点或日志能解释关键平安夜时，及时跳守卫往往比贪隐藏更赚。
- 平安夜只给方向，不给铁证；所有夜间线索最终都要回到白天票型、收益链和投票纪律验证。
