# 角色当前策略（经验，可能不完全正确）

必须服从固定规则和当局行动包；不得编造未收到的查验或夜间信息。核心目标：把真实查验转成当天能投、明天能验、死后能执行的公共方案。

## 一、查验目标

- 首夜优先验能改变票型的人：末置归票位、警下票仓、强势带队位、可能接徽位、发言难判但能控场者。验人理由必须说明：他有什么票权/话语权；查到好人如何用，查到狼人如何出。
- 对跳局通常不首验对跳者，优先验其金水、强站边者、警徽票仓、被两派争夺位。若验对跳者，必须说明结果如何直接改变明日放逐。
- 金水局不要满足于“保一个人”。金水要被安排任务：复述验人链、解释自己票型、争取摇摆票、在我死后按查验和票型带队。金水站错边时先纠偏，不因站错直接放弃。
- 连续查出金水时，要把金水分工：一人负责警徽/归票，一人负责复盘冲票与倒钩；金水不是天然正确，但是真实信息锚点。

## 二、起跳硬格式

每次起跳必须完整，逆风更不能省：

1. 我是预言家；昨夜查验对象和结果。
2. 为什么验他：位置、票权、发言预期、格局收益，避免只说“末置/警下所以验”。
3. 今天优先出谁；比较出查杀、出悍跳、出外置位的收益和风险。
4. 警徽流一、二顺位；验出金水/查杀分别怎么执行。
5. 若我倒牌：警徽给谁、已验信息如何执行、未验流不能机械出。

发言少喊“我真他假”，多拆悍跳三点：验人收益是否合理，警徽流是否服务控场，当天归票是否符合预言家视角。公开归票与实际投票必须一致；若因规则或局势改变，必须公开解释。

## 三、对跳日争票

- 有查杀时，先讲出查杀收益：验证预言家线、保留真预夜验、观察冲票和倒钩。但若对方拿警徽或归我，必须同时比较“先出悍跳”和“先出查杀”的收益，不能只重复查杀力度。
- 接查杀起跳或被归真预时，第一时间解释狼人收益：断真预查验链、抢警徽、借金水/强神控场、把查杀狼救过轮次。
- 失警徽或逆风时必须逐位争票，至少点名：自己的金水、对方金水、警下票仓、强神、独立摇摆位。逐人回应其核心疑虑，不只喊大票仓。
- 对“你票仓太顺/验人模板/预设狼坑/抢轮次”的攻击，拆成：谁最早定调，谁复读，谁有独立疑虑愿意听回应，谁从回票获益。
- 对方金水若是女巫、猎人、守卫或强势好人，优先争取其独立判断，指出悍跳借其身份控场的收益。

## 四、处理自身票仓过顺

- 拿警徽或获得大票支持时，不要只享受顺风。主动拆自己票仓：坚定好人理由、可能倒钩、顺票未知、异常跟风位。
- 近全票支持我不等于全好；重点看谁投完后继续抗推我金水、未验流或强神，谁用“太顺”制造好人回票。
- 若好人担心我票仓太顺，给验证方案：今天出悍跳/查杀，明天复盘最早保狼、关键救票、认错后继续带新抗推的人。
- 顺风局出狼后，次日不要直接按“反近全票”或“低信息”归人；先找倒钩和收益链。

## 五、警徽流、改验与传徽

- 警徽流不是狼坑名单。给流时必须说“验此人解决什么关系”；我倒牌后，未验到的警徽流不能机械出。
- 改警徽流或改夜验必须留下触发条件：谁承接悍跳链最深，谁救票获益，谁因强神信息/票型变化必须先拆。
- 白天声明传徽规则：若我夜死，传给已验金水或明神；若夜验更新导致传徽对象改变，以实际接徽表示昨夜验人更高优先级，但必须尽量提前说明这种可能。
- 若传徽会让未验人被误认金水，或金水身份无法公开导致严重歧义，遗言中说明已公开查验、传徽含义和风险；必要时毁徽，但必须解释原因。

## 六、票型分层

每天至少给最小结构：

- 冲票狼：早定调、复读同一攻击点、无视验人收益、强推真预或真预金水。
- 承接狼：连续警徽票/放逐票站错，悍跳死后继续叠遗言、转推新抗推位。
- 倒钩狼：投对悍跳或跟真预票，但之后从近全票、刀口、毒口、传徽歧义、未验警徽流中获益。
- 被骗好人：有具体疑虑，愿意听回应，有求证和摇摆痕迹，不急着打死真预链。
- 暂放位：理由与狼队不同，未吃明显收益，可通过明日查验或票型再看。

投对票、回头票、跟真预票只能暂降，不能洗白。若后续继续推真预金水、机械出未验流、借假遗言转火，重新升高优先级。

## 七、强神、死亡与假遗言

- 强神公开信息要重视，但未证身份声明、刀口猜测、毒口叙事不能推翻系统查验。
- 无对跳女巫、猎人、守卫声明时给容错：先要求对跳和解释收益，再比较外置放逐，避免把真预归票压到强神导致链条崩坏。
- 若女巫毒到对跳、悍跳金水或查杀链人物，要明确：毒口不是刀口坐实；先核身份、夜死原因、谁借死亡信息推翻真预链。
- 验人对象或对跳夜死时，不把死亡原因单独当作推翻验人的依据；结合公开强神信息、票型收益和已验链验证。

## 八、归票原则

- 当天归票必须服务查验链和公共收益。出未验外置位时，必须比较它与出查杀、出悍跳、出连续站错边位的收益；否则容易被认为承接悍跳遗产。
- 有真实查杀且查杀未明神自证时，默认优先落地查杀；若先出悍跳更能保真预链和警徽权，必须讲清理由。
- 金水被假查杀或假遗言污染时，先公开系统查验优先级，再要求全场复盘谁借污染获益。

## 九、遗言模板

遗言短而可执行：

- 身份；全部已公开查验和结果。
- 今天谁在抗推我，谁在救谁，谁复读核心攻击点。
- 明天必出位1名；优先复盘/验位2-3名；暂放位若干，并说明暂放条件。
- 警徽链和传徽含义；未验警徽流不能机械出。
- 若当天误推出好人，不机械继承其遗言定狼；重新看谁推动、谁获益、谁借遗言转火。

所有判断回到真实查验、公开票型、发言收益和可验证的明日执行；不要把单局偶然结果写成绝对规则。
