# 角色当前策略（经验，可能不完全正确）

## 总原则
- 猎人先是好人的纠偏位，其次才是临终枪口。
- 所有判断同时看四件事：身份闭合、票型收益、夜刀收益、污染链。
- 宁可晚一点开枪，也不能把枪口建立在旧站边、旧印象或单次发言上。

## 白天判断
- 默认保留两套世界，不因查杀狠、发言强、票多、金水或警徽就立刻坐死身份。
- 看到票仓过热、近全票过快、共识形成过快时，必须立刻做三件事：
  1. 指出异常从哪里来；
  2. 给出替代归票；
  3. 点出谁从这轮结果中获益。
- 只要发现两条以上狼点，就不能只口头怀疑，必须落到投票或强追问。
- 优先审查：接过污染警徽、遗言、假查杀后仍持续获益的人；与已出狼人长期同票、互保、共同转火的人；夜刀持续清理其反对者的人。

## 对身份链的处理
- 警徽、遗言、假查杀、金水都不是天然可信信息，必须看后续行动是否闭合。
- 无对跳神职要给高保护权重，但不能盲信；要核对其发言、投票、验人/毒口与死亡结果是否一致。
- 若某位是接徽位、遗言继承位或被污染链裹挟的关键位，必须额外检查谁在借这条链获益。

## 拍猎时机
- 通常不首日自曝；但若不拍会让真预、女巫、守卫或关键好人被近全票冲出，应提前拍。
- 优先拍猎的情况：
  1. 我被查杀且即将出局；
  2. 我被污染警徽强归；
  3. 真预或关键好人被错误推到高危，而我能用身份拆票；
  4. 场上好人票型已被接徽位控制；
  5. 有人悍跳猎人。
- 拍猎后不能只自证，必须同时给出：最疑狼坑、污染链、当轮归票、夜死后的枪口顺位。

## 归票规则
- 发现共识过快或近全票时，必须做反共识检查：谁先定调、谁在复读、谁在借表水差强推、谁在回避更危险的接徽位或收益位。
- 当“发言瑕疵”和“长期票型收益”冲突时，优先看长期收益。
- 若当前归票来自可疑警徽位或接徽位，必须明确给出替代归票，并说明该位与警徽链、票型、夜刀或假查杀的关系。
- 低存在感位不等于低危险位；若其持续承接同一条收益链，优先级要高于单次发言更吵的人。

## 开枪前快速清单
死亡触发猎人反应时，按顺序检查：
1. 目标是否有两类以上硬证据，而不是只靠一句发言、情绪、攻击我或单次投错？
2. 目标是否接过可能污染的警徽、遗言或假查杀，并持续从中获益？
3. 目标是否多轮归错票，且错误都让同一条污染链或自己安全获益？
4. 夜刀是否在清理目标的反对者，或让目标获得更大带队空间？
5. 是否有更核心的带队狼、连续同票抱团位、悍跳同向位，比低存在感位置更该开？
6. 我的枪口是否只是沿用旧站边、旧印象或票仓过顺？如果是，必须降级。
7. 目标若可能是真预、无对跳神职，且被可信闭合链支持，原则上不开，除非有更强身份冲突。

## 枪口优先级
优先开：
- 接污染链后仍连续归错票、持续压同一抗推位的人；
- 与已出狼人连续同票、互保、共同转火的人；
- 夜刀明显压制其反对者后仍持续获益的人；
- 已出狼人链条上的隐蔽帮手；
- 明面接徽位可白天处理时，其更隐蔽的同向帮手。

降低优先级：
- 只因单次措辞差、情绪化或投错一票，但后续有清晰回头和实际纠错的人；
- 主要在拆污染链、质疑假链条、且身份风险高的神职或好人；
- 公开身份、无对跳、且被可信闭合链支持的人；
- 证据不足且可能是关键好人的位置。

## 不开枪与留枪
- 如果信息不足、目标证据不够或误杀核心好人的风险过高，可以不开枪。
- 不开枪也必须留下具体顺位：最疑狼、其同向帮手、下一层继续查谁。
- 白天主嫌已出局或新信息推翻旧站边时，必须立刻更新枪口顺位，不能让枪留在旧印象上。

## 末轮与残局
- 末轮不要只看谁发言自然，要看谁救过狼、推过好人、从夜刀中获益、在关键票上拆过好人票。
- 明猎残局要把自己当公共好人约束，要求每名玩家解释全程票型、夜刀收益和完整狼坑。
- 开枪命中一狼后，仍要继续追同票帮手、切割者和顺势转火位。
- 若自己已公开身份，更要强制复盘“谁从这轮出局获益”，避免被场面情绪和顺推节奏带跑。
