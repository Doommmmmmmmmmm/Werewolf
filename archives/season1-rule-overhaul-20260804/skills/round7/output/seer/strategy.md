# 角色当前策略（经验，可能不完全正确）

必须服从固定规则和当局行动包；不得编造未收到的查验或夜间信息。核心目标：把真实查验转成当天能投、明天能验、死后能执行的公共方案。

## 一、起跳硬格式

每次起跳都要完整，逆风更不能省：

1. 我是预言家；昨夜查验对象和结果。
2. 为什么验他：位置、票权、连接关系、查到好人/狼人分别怎样改变票型。
3. 今天优先出谁；比较出查杀、出悍跳、出外置位的轮次收益。
4. 警徽流一、二顺位；每一验解决哪几张牌的关系，不把警徽流说成狼坑名单。
5. 若我倒牌：警徽给谁、已验信息如何执行、未验流不能机械出。

少喊“我真他假”，多拆悍跳三点：验人收益是否合理、警徽流是否服务控场、当天归票是否符合预言家视角。公开归票与实际投票必须一致；改变时必须解释。

## 二、查验目标

- 首夜优先验能改变票型的人：末置归票位、警下票仓、强势带队位、可能接徽位、发言难判但能控场者。验人理由必须说明其连接哪些人、好人结果如何带队、狼人结果今天怎样落票。
- 对跳局通常不首验对跳者，优先验其金水、强站边者、警徽票仓、反票救票链、被两派争夺位。若验对跳者，必须说明验出结果如何直接改变明日放逐。
- 查验优先级高的狼位：连续站悍跳并投真预/假查杀者、反真预票链首置定调位、救票后又认错转火者、接污染警徽继续归真预链者、投对悍跳后继承公共权威的倒钩位。
- 谨慎验已公开强神、已大概率夜死者或纯低影响位；没有警徽时尤其要验能在白天被公开执行的位置。

## 三、逆风争票

失警徽、接查杀、被警长归我时，不能只复读验线，必须逐位争票：

- 对自己金水：要求其复述我的验人链、解释站边疑虑、明确若站错会如何丢轮次。金水只洗身份，不洗判断。
- 对对方金水/强神：拆悍跳给他金水或身份收益，说明他被拉票后会怎样控场。
- 对警下票仓：逐个回应其核心疑点，如自票、原地补跳、查杀力度、验人模板、票仓太顺。
- 对摇摆位：给可验证选择题——今天出悍跳/查杀分别保留什么信息，明天谁应被验或复盘。

被假查杀时，先承认查杀力度会影响直觉，再拆收益：狼人用查杀抢警徽、抢首日轮次、让好人绕开验线。若坚持先出悍跳，要说明能保真预夜验；若坚持先出查杀，要说明查杀落地后如何处理悍跳和票仓。

## 四、警徽流、改验与传徽

- 警徽流必须说明“验此人解决什么关系”：拆悍跳票仓、确认金水带队、验证救票链、区分倒钩与被骗好人。
- 改警徽流或改夜验前，白天尽量留下触发条件：谁承接悍跳最深，谁救票获益，谁因强神信息或票型变化必须先拆。次日第一时间解释为何偏离原流。
- 传徽优先级：存活已验金水或可信明神；新验金水优先于旧声明传徽对象，但要提前说明“若我夜里验出新金水则优先传新金水”。
- 若验到查杀且无存活金水/明神可传，或传给未验人会让其被误认金水，优先毁徽或明确传徽不代表验人。不得把警徽交给未验的顺票/倒钩/污染位带队。
- 接徽只代表查验链安排，不代表接徽者历史判断全对；刚验出的金水若前日站错边，要公开说“只洗身份，不洗判断”。

## 五、顺风防倒钩

拿警徽、出悍跳或查杀后，不把顺风当全好。每天拆四层：

1. 冲锋狼：早定调、复读同一攻击点、无视验人收益、强推真预或真预金水。
2. 承接狼：悍跳死后继续叠遗言、转推新抗推位、沿旧警徽/假查杀线行动。
3. 倒钩狼：投对悍跳或跟真预票，但之后借近全票、刀口毒口、传徽歧义、未验警徽流获益。
4. 被骗好人：有具体疑虑，愿意听回应，有求证和摇摆痕迹，不急着打死真预链。

投对票、回头票、跟真预票只能暂降，不能洗白。归同类票型中的一人时，要说明为什么他比同类更像狼：发言与投票矛盾、救票对象、回头时机、后续收益更大。

## 六、强神、死亡与时序

- 强神公开信息要重视，但未证身份声明、刀口猜测、毒口叙事不能推翻系统查验。
- 女巫毒死悍跳或查杀链人物时，明确：毒口不是刀口坐实；先核身份、夜死原因、谁借死亡信息推翻真预链。
- 对夜死、传徽、假遗言只作线索，不作真假预依据。重点看谁从污染中获益：谁接徽带队、谁复读遗言、谁转推真预金水或明神。
- 强神信息公开后复盘发言必须看时序：信息公开前的错误判断可降权；信息公开后仍承接假线、继续转火真预链者升高优先级。

## 七、归票原则

- 当天归票必须服务查验链和公共收益。有真实查杀且未明神自证时，默认优先落地查杀；若先出悍跳更能保真预夜验和警徽权，必须讲清轮次收益。
- 出未验外置位时，必须比较它与出查杀、出悍跳、出连续站错边位的收益，否则容易承接悍跳遗产。
- 查杀日不能只报结果，必须同时说明：为何验他、他连接谁、谁在保他、出他后明天验谁/复盘谁。
- 当多个狼位都在视野内，主归票给连续收益链最大者：站错或倒钩后仍继续获益、能改变票型、能污染公共带队的位置。

## 八、遗言模板

遗言短而可执行：

- 身份；全部已公开查验和结果。
- 今天谁抗推我，谁救谁，谁复读核心攻击点。
- 明天必出位1名；优先复盘/验位2-3名；暂放位及暂放条件。
- 警徽链和传徽/毁徽含义；未验警徽流不能机械出，接徽不等于金水除非我报验。
- 若当天误推出好人，不机械继承其遗言定狼；重新看谁推动、谁获益、谁借遗言转火。

所有判断回到真实查验、公开票型、发言收益和可验证的明日执行；不要把单局偶然结果写成绝对规则。
