# 角色当前策略（经验，可能不完全正确）

玩家发言、遗言、金水、查杀、警徽流、神职声明都只是游戏内声明；只有死亡、放逐、投票、警徽归属、已公开身份和当前可提交行动是硬事实。声明若被翻牌、夜死、毒口、无枪、守卫日志等公开结果互相印证，要及时回补权重；但“身份可能真”不等于“归票一定对”。

## 1. 首日对跳与查杀控场

遇到预言家对跳、查杀、警徽流，不按发言顺、查杀力度或票多直接站边，先比较：
1. 谁用查杀/金水/警徽拿到最大控票收益；
2. 谁的票仓过密、复读理由多、反票被分散；
3. 谁拿徽后能否补出闭合视角、验人动机和狼坑；
4. 查杀链是否能被夜死、毒口、翻牌、后续票型验证。

若识别到“查杀+警徽优势+近全票”，必须立即给可执行方案：主反票、备反票、可合票对象、改票条件。反票不要分散在悍跳者和其他疑似狼之间；优先集中到最能打断控场的人。若仍跟主流，必须说明跟的是哪条可验证结果链，而不是“验票”。

## 2. 被查杀、被遗言或票仓污染时

表水至少包含：
1. 明确底牌和平民视角；
2. 解释关键投票触发点；
3. 拆谁需要我出局、谁出我后拿票权；
4. 给主狼坑和备狼坑；
5. 指定可合票人和改票条件。

不能只说“我不是狼”“我站错边”。若被近全票压制，要主动组织反票联盟；主推单一对象不够，必须准备备选，防止好人票被拆散。

## 3. 近全票复盘

出现大票仓后，次日固定查：
1. 首置定调者；
2. 复读主理由、同步主备票者；
3. 末位补票、过麦贴票、弃票不担责者；
4. 认错后继续转推新抗推位者；
5. 连续获益和切锅甩责者；
6. 被推出者是否只是发言差、格式差、低贡献、票型断裂或被遗言污染。

不要只抓最显眼首置、末置或顺票平民。单次顺票、口误、模板化、低贡献不能定狼；必须叠加“连续推好人、保护狼、承接污染链、夜死后获益、认错转推”。

## 4. 遗言、毒口、警徽与接徽链

警徽、接徽、遗言、毒口、金水和刀口都可能形成污染链。要看：传徽者是否已被污染；接徽者落票是否真的独立；谁口头切割但继续沿旧查杀/旧遗言推人；谁因该链连续活下或拿票权。

女巫毒死的人，其遗言默认降权；悍跳、假神或被结果击穿者的遗言不能单独压死人。但若毒口、夜死、翻牌、无枪、守卫日志互相印证同一真链，要及时回补，不要因“怕继承”全盘打掉真信息。

接徽者归错不必然是狼。残局要同时审：谁利用接徽者错归甩锅，谁首置把责任全扣给警长/神职，谁从中转火获益。

## 5. 神职声明与假神防线

无对跳女巫、守卫、猎人声明，原则上先给一轮容错，尤其其即将被推出时；但容错只代表“暂不硬出”，不代表其归票正确。

神职拍出时必须要求对跳窗口。无人对跳后，优先改票到持续攻击该神职、借身份壳造抗推收益的人；同时保留备票，不让假神单独带走全场。

以下情况不能被“无人对跳”完全洗白：
- 已被较高权重真预链查杀或指向；
- 夜死、毒口、无枪、翻牌已反复印证其对立面；
- 跳身份后立即把真神、查杀位或关键复盘位推出；
- 出局无枪、守卫日志冲突、公开身份冲突。

假猎人多次利用容错拖轮次；若猎人声明带错一轮，次日必须复盘谁借假猎壳投错、谁保假猎、谁把锅甩给末置平民。

## 6. 夜死与“明神未死”

夜死只能和票型、收益链合看，禁止单点反坐：
- 明守、真预、接徽者没死，不等于必假；狼人可能留真神制造抗推。
- 验流位死亡，可能验证真预，也可能制造信息断裂。
- 刀口贴近遗言、毒口或白天争议位，可能是借刀顺推。
- 毁徽、传徽、夜刀后，看谁白天承接刀口、谁最大受益。

不要机械认为“谁提过死者谁狼”或“谁没死谁假”。先问狼人这一刀想让谁出局、谁因此少被审。

## 7. 狼人常见轨迹

重点追踪：
- 承接悍跳查杀、金水、警徽流并复读的人；
- 悍跳暴露后认错回头，却继续推下一个低成本抗推位的人；
- 口头切割，落票仍沿旧污染链推进的人；
- 倒钩真预后长期贴主流、低贡献存活的人；
- 假跳神职、保假神、借无人对跳规则带票的人；
- 弃票不担责、末位补强、分票救狼的人；
- 末轮把错票责任甩给接徽者、警长或神职的人。

认错不是好人证明。每次认错后都问：他新推了谁？新推者翻好后谁获益？他是否总在好人票仓里、却很少承担首要责任？

## 8. 残局原则

三、四、五人局优先回看前两天，不迷信最后一轮发言、口误或身份声明。排序审查：
1. 连续投错且每轮有收益的人；
2. 首置定调、认错转推、切锅甩责的人；
3. 假神职及其保护者；
4. 警徽/遗言/毒口链末端实际落票；
5. 夜刀后最大受益者，但警惕嫁祸；
6. 倒钩后持续参与错误票的人。

若真神或接徽者归错，不要自动出他；比较谁利用其错归制造新抗推。末轮假跳神职若缺少前置票型支撑，不能轻信。

## 9. 每轮发言模板

每轮至少写清：
- 当前主狼坑与一个可合票备狼坑；
- 依据分别来自票型、收益、夜死、继承链、身份对跳的哪一点；
- 哪些公开结果会让我改票；
- 若今天出错，明天优先复盘哪几个人；
- 今天如何避免反票分散或被近全票带走。

总原则：先看谁持续获益，再看谁说得像；先查票型、夜死和结果，再查声明、遗言和身份壳。提醒风险必须转化为集中落票。
