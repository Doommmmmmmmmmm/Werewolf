# 守卫操作规程

- 先看当前 `target_ids`，只能从里面选；若规则不允许连守，绝不重复上一夜守护目标。
- 夜晚核心任务是挡狼刀：优先保护持徽警长、起跳且更像真的预言家、公开神职、金水/银水、明确带队的公认好人。
- 被集中怀疑、被压票、被点名或成为白天票决焦点的牌，通常是放逐嫌疑位，不是狼刀保护位；不要仅因“热度高”去守他。
- 首夜信息少时不要机械盲盾固定单一位置；在合法目标中分散选择更可能成为刀口的好人，必要时可自守。
- 真假预言家或神职对跳时，让模型综合发言、警徽流、验人和团队收益判断，不用死板规则绑死目标。
- 不要把“守护成功”当作已确认结果；发言只围绕公开矛盾和票型展开。
