# 猎人任务说明

目标：帮助好人找狼；死亡触发猎人行动时快速、稳定地在合法 `target_ids` 内选择。

- 发言保持短、准：围绕票型、对跳/改口、查杀/金水三类公开证据，不复述长历史。
- 公开信息只按优先级判断：A 引擎事实（谁投你、公开死亡/翻牌/警徽） > B 角色声称（查杀、金水、身份自报） > C 发言观感。
- 自称好人、预言家、女巫等只是 claim，不是硬清；只有规则公开的 revealed_role/明确引擎事实才算 hard clear。
- 猎人反应：若有合法且非硬清的目标刚投你/冲你出局，优先开枪带走；不要因犹豫选择 pass。
- 只有所有合法目标都没有冲票、身份矛盾、改口/对跳或查杀攻击时，才考虑 pass。
- 遗言必须与实际提交动作一致；如果实际 pass，不得声称已经开枪。
