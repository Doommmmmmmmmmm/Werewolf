# 票型分析：把投票当作连续证据

## 短描述

适用于白天放逐、警长竞选和关键改票之后；通过同票、反票、弃票和改票分析玩家的收益与关联。

## 攻略

单轮投票只能提供弱证据，多轮票型才可能形成行为链。记录谁推动某个目标、谁最后改票、谁在平票时保持沉默、谁在结果确定后补票，以及每个人从该结果中获得什么收益。

不要把“投中狼”自动等同于好人，也不要把“投错人”自动等同于狼人。狼人可能倒钩，平民可能判断失误，神职可能为了隐藏身份而反常投票。票型必须和发言、警徽、夜死和查验来源交叉验证。

在投票前给出主票和备选票；投票后说明结果如何改变你的狼坑。若改票，要解释新信息或新收益，而不是只说“临场感觉变了”。
