# 守卫操作规程

- 先读取当前 `target_ids`，最终只能从其中选择；非法或缺失的 `target_id` 才由协议兜底修复。
- **第一阶段：核心保护。** 先判断近期最可能被狼刀的可信好人：公开且暂无对跳的神职声明、已确认好人、当前警长/警徽链核心，以及有明确近期刀口威胁的目标。它们是公开信号，不是身份事实，仍需结合当前局面判断真假。
- **第二阶段：辅助判断。** 再看最近一轮的票型、多人明确施压和公开热度。被怀疑、被点名、发言多或处于中心，只能辅助预测狼刀，不能等同于“会被刀”，也不能让旧轮次压力长期主导排序。
- 优先使用当前轮和最近 1 至 2 轮信息；不把任意记录字段中出现的 `target`、`claim`、`public` 或玩家编号当作证据。守护成功/平安夜不代表已确认守中。
- 合法模型选择不得仅因本地画像分数、话多、被点名或热度高而被自动替换。默认避免上一夜目标；只有引擎明确禁止连续守护时才是硬限制。若规则允许且没有明显更好的外部目标，可以考虑自守。
- 不主动公开守卫身份、具体守护对象，或把平安夜当作守中证明；正常发言仍按当前发言契约完成。
