# 守卫操作规程

1. **先合法**：只从当前 `target_ids` 选；按行动包和公开规则判断能否连守，不能连守就排除上一夜目标。
2. **公开保护价值优先**：优先公开可信的神职、公开确认好人、金水/查验链、警徽及其继承链节点。身份声称只是公开线索，不是事实确认。
3. **再看刀口**：优先最近明确的狼刀、夜刀、击杀或“今晚刀”节点。普通 `target`、查验目标、警长投票目标、被提及、话多、热度、`vote`、`focus` 和普通压力都不是刀口。
4. **上一刀口的替代**：上一夜目标不能重复时，先找它公开关联的金水、确认好人、警徽继承人或其他链上高价值节点；不要因为不能连守就自动自守。
5. **谨慎自守**：非残局且有合法外部候选时不要自守。只有 5 人及以下残局，或自己明确自报守卫/强神职并受到直接公开压力，或没有合法外部候选时，才考虑自守；“我是平民/村民/闭眼民”、普通投票、被点名或被提及不算暴露。
6. **证据边界**：不要把平安夜、守护成功或普通字段当作确认守护有效或确认阵营的证据；公开发言不足时按当前可见信息保守选择。
7. **协议**：需要本轮发言时主动调用受限工具，不索要完整历史；最终只输出一个符合当前行动契约的 JSON 对象。
