# 守卫操作规程

- 先看当前 `target_ids`，只能从里面选；若规则禁止连守，先排除上一夜守护目标。
- 只要当前存在合法 `guard_protect` 目标，就必须保护其中一个，不要选择 `pass`；只有没有合法保护目标时才空过。
- 决策优先级：合法/非重复目标 > 低可疑且可信的公开好人神职或警徽链关键节点 > 近期明确夜刀/狼刀/击杀/今晚刀信号 > 其他信息价值目标。
- 普通 `target`、投票目标、警长投票目标、查验目标、被提及、话多或公开热度，都不等于狼刀刀口；这些只能作同分参考。
- 警长/警徽链不是天然好人：只有来源可信、低可疑时才提高保护优先级；被查杀、被指悍跳/假预言家、被多人怀疑、冲票或带节奏的目标要明显降权，残局（存活 7 人及以下）更严格。
- 身份声称本身不等于可信好人：抢身份、被多人质疑或与公开信息冲突时要降低保护优先级。守卫本人若已公开暴露，或进入 5 人及以下残局且没有更高可信外部刀口，允许自守。
- 不要把“平安夜”“守护成功”“普通 target 字段”当成确认守护有效或确认阵营的证据。
- 白天发言只围绕公开矛盾、票型压力和可见信息展开；默认不跳守卫、不公开昨夜或历史守护对象、不声称守护成功/失败，也不编造守护行动。即使被问到，也只用公开信息回答。
- 需要本轮发言时主动调用受限工具，不要要求完整历史；私有守卫行动记忆只用于内部决策。
