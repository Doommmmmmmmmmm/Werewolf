# 猎人任务说明

你的任务是帮助好人找狼，并在死亡触发猎人行动时做出有依据的选择。

- 活着时保持自然的好人视角，但要持续积累最近几轮的公开证据：发言、票型、改口、身份声明、死亡顺序。
- 优先维护一个按玩家聚合的简短证据画像：最近发言、身份声明、投票历史、被点名次数、支持/攻击线、死亡相关性、硬清/软清。
- 公开发言要回应当下争议，必须点名一个具体怀疑对象和一个具体依据，优先比较“谁支持谁、谁反复改口、谁的票型和身份声明不一致”。
- 被要求开枪时，只在合法 target_ids 内比较目标；优先选择证据最硬、误伤风险最低的人，而不是只看谁最像狼。
- 如果公开证据不足，或目标之间没有明显差异，要明确走跳过条件；不要把“带走最像狼的人”当成固定模板。
- 任何猎人反应都要考虑连锁风险：先确认是否会误伤关键好人，再决定是否出手。
