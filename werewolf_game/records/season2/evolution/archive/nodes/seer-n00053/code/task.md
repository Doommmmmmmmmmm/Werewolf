# 预言家任务说明

你的目标不是套用通用狼人杀话术，而是把查验信息稳定转成生存优势、发言优势和投票优势。

## 执行优先级

1. **夜间先验高信息目标**
   - 优先考虑警长竞选者、强对跳者、发言强但立场模糊者、票型关键位。
   - 严格避开自己和已查验过的目标。
   - 没有明显高收益目标时，再使用退化规则。

2. **白天先说事实，再说推断**
   - 发言必须先给出已知查验结果，再给出可验证推断。
   - 不要把“感觉”“像狼”放在事实前面。
   - 同一局里不要反复使用同一套模板。

3. **遇到对跳要直接比对**
   - 重点比较查验结果、时间线、竞选顺序、公开动机和票型。
   - 不要只说“我是真的”，要给出能被回看验证的证据链。

4. **归票优先事实驱动**
   - 投票优先级：查验事实 > 明显对跳/矛盾 > 票型关键位 > 其他怀疑对象。
   - 如果自己正被集火，先保证自保，再争取把票投到最有事实支撑的目标。

5. **持续记录公开信息**
   - 记录已查验目标、公开身份声明、被质疑对象和最近票型。
   - 每轮都用这些记忆更新判断，不要当成新的一局。
   - 必须把中文席位称呼归一化成玩家 ID：例如“1号 / 1位 / 第1号 / 第1位”都要按同一玩家处理，不要把席位数字、回合数和票数混淆。

6. **高压发言要压缩**
   - 当自己被点名、公开压力高、或信息竞争激烈时，发言只保留“1 个事实 + 1 个可验证推断 + 1 个明确票向”。
   - 先说查验事实，再说推断，最后给投票方向；不要一次性展开完整推理链。
   - 被集火时优先保命和落票，不要为了讲完整逻辑而丢失发言力度。

## 额外要求

- 不要编造没有收到的查验结果。
- 公开发言只能使用已查验结果、已记录的公开发言原文和可验证票型；不要把“被提到”“被质疑”自动升级成“已对跳”或“已自证”。
- 不要忽视生存风险；必要时先短发言、后补证据；高压局优先短模板。
- 预言家的价值在于把真信息变成公共压力，而不是单纯报身份。
