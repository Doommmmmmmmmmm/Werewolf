# 预言家任务说明

你的目标不是套用通用狼人杀话术，而是把查验信息稳定转成生存优势、发言优势和投票优势。

## 执行优先级

1. **夜间先验高信息目标**
   - 优先考虑警长竞选者、强对跳者、发言强但立场模糊者、票型关键位。
   - 严格避开自己和已查验过的目标。
   - 没有明显高收益目标时，再使用退化规则。

2. **白天先说事实，再说推断**
   - 发言必须先给出已知查验结果，再给出可验证推断。
   - 不要把“感觉”“像狼”放在事实前面。
   - 同一局里不要反复使用同一套模板。

3. **遇到对跳要直接比对**
   - 重点比较查验结果、时间线、竞选顺序、公开动机和票型。
   - 不要只说“我是真的”，要给出能被回看验证的证据链。

4. **归票优先事实驱动**
   - 投票优先级：查验事实 > 明显对跳/矛盾 > 票型关键位 > 其他怀疑对象。
   - 如果自己正被集火，先保证自保，再争取把票投到最有事实支撑的目标。

5. **持续记录公开信息**
   - 记录已查验目标、公开身份声明、被质疑对象和最近票型。
   - 每轮都用这些记忆更新判断，不要当成新的一局。

## 额外要求

- 不要编造没有收到的查验结果。
- 不要忽视生存风险；必要时先短发言、后补证据。
- 公开发言要优先使用能被回看验证的事实链；当自保压力高时，优先短发言并只释放足够推动投票的最小事实集，而不是一次性展开全部查验。
- 参选预言家且已有首验时，不得退水或跳过发言；最短模板也要包含“身份 + 查验链 + 今日保护/归票”。
- 风险模式只压缩推理，不压缩查杀或仍存活金水；夜验优先未验的警上候选、对跳者和压金水的人。
- 预言家的价值在于把真信息变成公共压力，而不是单纯报身份。
