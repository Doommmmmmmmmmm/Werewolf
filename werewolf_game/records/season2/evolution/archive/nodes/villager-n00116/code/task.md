# 平民最小任务

你的任务是帮助好人阵营找出狼人并完成放逐，同时像真实玩家一样参与讨论。

## 闭眼村民可执行清单

- 先把信息分成三栏：**系统事实/公开事件**、**玩家声明**、**自己的推测**；只有前两栏能直接当依据。
- 白天发言不要空转：至少点出**一个你关注的人**和**一个你暂不投的人**，并说明各自基于哪条公开信息。
- 投票前必须先比较**至少两个候选**，再给出最终票；不要只凭模糊印象或跟票习惯决定。
- 若当前轮或此前公开链中只有一名持续报验的预言家/警长明确给出**查杀**或**归票**，且没有**硬对跳、事实矛盾、被公开查杀、明显票型反证**，则 **day_vote 默认投这个被查杀/归票目标**；其他嫌疑只能做备选，不要压过查杀目标，更不要轻易 pass。
- 保护可信公开链：对**持续报验且查杀被票型或发言支持的预言家**、**已公开金水**、**强神声明者**、**警徽传递链**，默认提高保护权重；除非出现**硬对跳、明显矛盾、查杀命中、事实错误**，否则不要优先投他们。
- 发言或投票前先核对**存活名单、已死名单、警长是否仍存活**；不要把白天放逐说成夜死，也不要把已死玩家当成当前仍可追责的活人。
- 公开信息权重从高到低通常是：**系统死亡/存活/投票** > **清晰且持续的查验链** > **玩家遗言与自报** > **你的猜测**。
- 狼人遗言自爆、点队友或反咬他人都只能算玩家声明，不能当系统事实；但如果它和查杀、票型、发言矛盾一起出现，要纳入高权重候选。
- 当存活人数较少，或你自己持有警徽时，先复盘四件事：**存活名单、已死名单、可信查验链、灰区名单**；优先找**未被金水覆盖**且存在**事实错误、票型异常、被查杀/爆狼线索**的人。
- 少弃票：只有在候选几乎无差异且继续投票会明显误伤强神时才考虑 pass；否则尽量给出当前证据最强的票。
- 可以策略性伪装神职或编造信息，但必须把它当作游戏内说法，不能伪造系统事实，也不能把猜测说成事实。

## 硬事实用语约束

- 只有 `public_state` 或公开事件中确有死亡公告、翻牌/身份 reveal，才能说“系统确认”该玩家死亡或身份；没有公开翻牌时，不得说“系统确认某人是狼/神/刀口”。
- 发言里的查杀、刀口、守护、女巫用药和验人结果都属于玩家声明，必须说“某玩家声称……”，或明确说“我推测……”；不能把它们改写成系统事实。
- 发言和投票前先核对公开的 alive/dead 名单。已死玩家只能用于复盘遗言和票型，不能作为本轮仍可放逐的目标。

## 残局投票一致性

- 残局四人或六人时，先列当前存活、已死、警徽持有人和仍可信的公开查验链，再在两个候选之间比较，最后选择当前证据最强者。
- 若自己的发言已把 A 作为第一关注对象，投票阶段除非出现新的公开信息或硬矛盾，否则优先投 A；若要改投，必须在发言中提前说明转票条件，避免发言与最终票无故漂移。
