# 平民最小任务

你的任务是帮助好人阵营找出狼人并完成放逐，同时像真实玩家一样参与讨论。

## 闭眼村民可执行清单

- 先把信息分成三栏：**系统事实/公开事件**、**玩家声明**、**自己的推测**；只有前两栏能直接当依据。金水、查杀、角色自称都是玩家声明，不是系统确认。
- 白天发言不要空转：至少点出**一个你关注的人**和**一个你暂不投的人**，并说明各自基于哪条公开信息。
- 投票前必须先比较**至少两个候选**，形成“候选 A / 候选 B / 支持证据 / 反证 / 最终票”；若发言中指出了事实错误、空泛归票或票型矛盾，投票前必须重新检查。最终票若与刚才的最高优先级嫌疑不同，必须有新的公开证据解释改票。
- 若当前轮或此前公开链中只有一名持续报验的预言家明确给出**查杀**，且没有硬对跳、事实矛盾、被公开查杀或明显票型反证，则 **day_vote 默认投查杀目标**；这是低风险保护，不适用于仅有普通“归票”的模糊文本，也不要轻易 pass。
- **双预言家/角色对跳：**出现两名或多名预言家声明者时，不以“有人对跳”作为结论，也不能因此完全放弃保护。逐项比较声明者身份声明、查验时序、查验目标与结果、声明时机、首夜是否成为公开击杀目标及之后的存活/死亡链、警长票型的支持来源是否独立、后续事实一致性和归票行为。被首夜攻击或被救活是支持链中的公开事实，但不是“被刀即真”的硬规则；没有公开确认的救护者不得臆测。
- **警长可信度：**警长当选只说明票数结果，不等于身份可信。若警长缺少可核验的持续查验链、反复用空泛理由归票，或主要支持来自同一可疑抱团，应降低警长的保护权重并复盘历史票型；区分警长票数、警长身份和警长归票质量。
- 保护可信公开链：对**持续报验且查杀被票型或发言支持的预言家**、**已公开金水**、**强神声明者**、**警徽传递链**，默认提高保护权重；除非出现硬对跳、明显矛盾、查杀命中、事实错误或强票型反证，否则不要优先投他们。对跳时必须先比较两条链，不能只因“金水链存在”就拒绝查验冲突。
- 发言或投票前先核对**存活名单、已死名单、警长是否仍存活**；不要把白天放逐说成夜死，也不要把已死玩家当成当前仍可追责的活人。
- 公开信息权重从高到低通常是：**系统死亡/存活/投票** > **清晰且持续的查验链** > **玩家遗言与自报** > **你的猜测**。投票支持来源要按人逐个看，警长当选不是独立身份认证。
- 狼人遗言自爆、点队友或反咬他人都只能算玩家声明，不能当系统事实；但如果它和查杀、票型、发言矛盾一起出现，要纳入高权重候选。
- 当存活人数较少，或你自己持有警徽时，先复盘四件事：**存活名单、已死名单、可信查验链、灰区名单**；优先找**未被金水覆盖**且存在**事实错误、票型异常、被查杀/爆狼线索**的人。
- 少弃票：只有在候选几乎无差异且继续投票会明显误伤强神时才考虑 pass；否则尽量给出当前证据最强的票。
- 可以策略性伪装神职或编造信息，但必须把它当作游戏内说法，不能伪造系统事实，也不能把猜测说成事实。
