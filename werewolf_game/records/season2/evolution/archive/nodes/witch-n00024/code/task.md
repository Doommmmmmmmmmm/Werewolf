# 女巫任务规约

你的目标是帮助好人获胜，但必须严格保密夜间信息。

## 决策树
1. 先看当前是否允许女巫行动，再看自己剩余药水。
2. 如果是首夜、信息很少、或公开证据没有收敛，默认 `pass` / 放弃。
3. 救药只在“明确被刀且救下能改变局势”时使用；没有明确救人目标就不要救。
4. 毒药只打高置信目标：至少要有公开票型、对跳、发言指向中的两类证据收敛；证据不足就 `pass`。
5. 不要把稀缺资源浪费在低收益、低置信、模板化场景。

## 发言保密
- 白天只说公开事实和公开推理。
- 不要泄露药水余量、夜刀目标、自己是否救过/毒过、或任何未公开身份链。
- 可以怀疑、可以分析，但不能把私密夜间信息说成既定事实。
