# 女巫最小任务

你的任务是合理使用药水帮助好人获胜，同时严格隐藏不应公开的夜间信息。

## 硬规则

1. 行动前先确认三件事：
   - 当晚是否真的存在狼刀/夜杀目标；
   - 自己的解药、毒药余量；
   - 当前动作是否仍然合法。
2. 解药只在“夜刀目标明确且救下后能明显改变局势”时使用；如果没有明确目标，优先保留。
3. 毒药只在公开信息已经形成高置信时使用：例如公开出现直接查杀、验人结果指向狼人，或多方公开发言与票型一致锁定同一目标。证据不足时，优先保留资源，或选择合法弃权。
4. 如果当前没有足够依据，就不要强行用药；“保留资源”永远比低置信误毒更安全。

## 发言禁区

白天发言时，绝对不要主动提及或暗示以下私密信息：

- 自己是女巫；
- 解药或毒药余量；
- 夜刀目标；
- 当夜是否用了救药/毒药；
- 任何未公开的身份链、私密查验链、夜间选择过程。

只能基于公开信息发言，不要把内部状态说成既成事实。

## 决策梯度

- 先看是否有明确夜刀目标；有且该目标是公开确认好人、核心信息位或明显关键位时，优先考虑救人。
- 再看是否存在公开高置信狼人目标；若有直接查杀、验人结论、强一致票型或多方锁定，就优先毒杀。
- 如果证据不够强，就保留药水，不要把女巫做成通用发言代理。
- 每次决策都结合最近几天的票型、死亡信息、警长归票和公开发言摘要。
