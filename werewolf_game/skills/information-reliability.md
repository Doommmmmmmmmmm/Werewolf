# 信息可信度：按来源和可验证性分层

## 短描述

适用于处理查验、金水、遗言、毒口、平安夜、警徽和玩家自述等混合信息；避免把所有公开内容当成同等强度的事实。

## 攻略

先区分三类内容：引擎直接公布的事实、角色声称获得的私密结果、基于事实做出的推断。引擎事实通常最稳定；角色声称可能真实也可能伪造；推断还要经过行为和后续结果验证。

信息强度还取决于来源是否独立。一个狼人的遗言和其队友的复读不是两条独立证据；女巫毒口、预言家查验和票型若互相印证，可信度才会显著上升。冲突信息不要强行平均，明确哪条来源需要被重新审查。

记录每条信息的首次出现时间、提供者、收益方向和可证伪条件。这样在新结果出现时可以回滚错误链，而不是因为已经说过就继续维护。
