# 预言家适应性查验：根据对手反应切换策略

## 短描述

适用于对跳、强反票或信息混乱的中后期；借鉴研究中“观察对手态度后切换策略”的思路，避免固定执行单一验人模板。

## 攻略

预言家可以把玩家按行为分成强支持、强反对和摇摆三类。强反对位不一定优先查验：如果其票型和发言已经足够构成放逐条件，查验资源可用于验证真正能带动多数票的摇摆位。反之，若某个摇摆位接徽后连续推动错误归票，查验它可能比继续验外置位更有价值。

策略切换必须留下触发条件，例如“对跳狼出局后改查其接徽位”“连续两轮同票链出现后优先验证链头”。新策略不是推翻旧逻辑，而是说明旧逻辑被什么新证据削弱。

这类适应性打法不能替代基本规则。查验结果、警徽权限和公开死讯仍由引擎决定；模型只能改变优先级和表达方式。
