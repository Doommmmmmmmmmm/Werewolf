# 倒钩狼：用好人视角切断狼队关联

## 短描述

适用于悍跳狼发言或票型已经接近崩盘、狼队需要切断关联时；重点是保持自然的好人判断，而不是为了倒钩而刻意踩队友或站死某一边。

## 攻略

倒钩狼要把自己当成没有团队的好人牌来行动。不要因为知道队友身份，就强行冲票、保人或复读队友的说法；先判断发言和票型，再决定是否与队友同票。必要时可以公开指出队友的漏洞，甚至在确定冲票不会改变结果时坚决把队友投出去。

警上前置位应先建立干净、稳定的第一印象，避免出现“为了做身份而做行为”的痕迹。后置位则可以比较两名预言家的验人理由、警徽流、狼坑和归票收益；如果队友悍跳已经聊爆，倒钩可以明确指出问题，但要给出自己的完整逻辑，不能只留下一个“我反对队友”的姿态。若自己的状态不够阳光、容易成为焦点，通常不适合上警抢镜，可以选择警下发言。

警下要盘双边逻辑：分别说明两名预言家的好坏面，再给出当前站边和改变站边的条件。不要开局就把一方认成绝对真，也不要为了证明自己倒钩而习惯性猛踩狼队友。倒钩狼最终仍需要把好人推出去，因此可以从早期开始指出一两个外置位的可疑点，为未来的抗推留下合理伏笔，但力度应随信息增加而调整。

倒钩的常见收益是：卖掉悍跳队友、避免进入警徽流、在队友翻车后留在好人票仓，或在关键轮次穿神职衣服挡刀。自刀不上警也可能制造深水位，但要考虑女巫不救、遗言暴露和狼队损失关键轮次的风险。更复杂的“格式”需要队友配合制造不见面、退水和金水关系，不能在没有沟通或不符合当前板子的情况下硬套。

倒钩不是“永远站真预”或“永远卖队友”。每次公开行为都要能回答三个问题：为什么此刻这样判断、如果队友是好人该如何解释、下一轮什么新信息会让我改变。若切割已经被票型、查验或遗言击穿，应停止维护旧身份，及时换成新的、可解释的生存路线。
